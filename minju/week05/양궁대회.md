# 양궁대회

화살 하나의 점수를 모두 더하는 문제가 아니다. **각 점수 구간의 승자가 그 점수를 한 번 가져간다.**

예를 들어 9점 구간에서 어피치가 1발, 라이언이 2발을 맞히면 라이언이 가져가는 점수는 18점이 아니라 9점이다.

| 상황                                         | 점수를 가져가는 사람 |
| -------------------------------------------- | -------------------- |
| 라이언 화살 > 어피치 화살                    | 라이언               |
| 라이언 화살 ≤ 어피치 화살, 둘 중 하나라도 쏨 | 어피치               |
| 둘 다 0발                                    | 아무도 가져가지 않음 |

추가로 기억할 조건은 세 가지

1. 라이언이 **양수의 점수 차이**로 이겨야 한다.
2. 화살 n발을 모두 사용해야 한다.
3. 최대 점수 차이가 같으면 0점부터 1점, 2점 순서로 비교해 화살이 더 많은 배열을 고른다.

배열의 인덱스와 점수는 반대 방향이다.

| 인덱스    | 0   | 1   | 2   | …   | 9   | 10  |
| --------- | --- | --- | --- | --- | --- | --- |
| 과녁 점수 | 10  | 9   | 8   | …   | 1   | 0   |

따라서 현재 점수는 `10 - idx`로 계산한다.

## 왜 DFS?

어떤 점수들을 가져올지 선택해야 한다. 10점에 화살을 많이 쓰면 다른 점수에 쓸 화살이 부족해질 수 있으므로, 높은 점수부터 무조건 가져오는 방식은 정답을 보장하지 않는다.

각 점수에서 가능한 선택을 나누어 모두 확인해 보자.

**현재 점수를 가져오거나, 포기한다.**

10점부터 1점까지 10개 구간에서 두 가지 선택을 하므로 선택 조합은 최대 `2^10 = 1024`개다. 충분히 전부 확인할 수 있다.

## 왜 화살 개수를 두 가지로만 정해도 될까?

어피치가 9점에 2발을 쐈다고 하자.

| 라이언 화살 | 결과              | 판단                       |
| ----------- | ----------------- | -------------------------- |
| 0발         | 어피치가 9점 획득 | 포기                       |
| 1~2발       | 어피치가 9점 획득 | 화살을 써도 결과가 같음    |
| 3발         | 라이언이 9점 획득 | 이기는 데 필요한 최소 개수 |
| 4발 이상    | 라이언이 9점 획득 | 점수를 더 받지 못함        |

따라서 1~10점 구간에서는 아래 두 경우만 확인하면 된다.

- 가져오기: `info[idx] + 1`발 사용
- 포기하기: 0발 사용

남는 화살은 마지막에 모두 0점에 넣는다. 점수 차이를 바꾸지 않으면서 n발을 전부 사용할 수 있고, 동점일 때 낮은 점수를 우선하는 규칙에도 유리하다.

```cpp
dfs(idx, remain, info, ryan, answer, bestDiff);
```

점수는 마지막에 배열 전체를 보고 계산한다. 처음에는 재귀 도중에 점수까지 관리하지 않는 편이 흐름을 이해하기 쉽다.

## 풀이

```cpp
#include <vector>
using namespace std;


bool preferLower(const vector<int>& candidate,
                 const vector<int>& answer) {
    // 인덱스 10이 0점이므로 뒤에서부터 비교
    for (int i = 10; i >= 0; i--) {
        if (candidate[i] != answer[i]) {
            return candidate[i] > answer[i];
        }
    }
    return false;
}

void dfs(int idx, int remain,
         const vector<int>& info,
         vector<int>& ryan,
         vector<int>& answer,
         int& bestDiff) {

    if (idx == 10) {
        // 남은 화살은 모두 0점에 사용
        ryan[10] = remain;

        int ryanScore = 0;
        int apeachScore = 0;

        for (int i = 0; i < 11; i++) {
            int score = 10 - i;

            if (ryan[i] == 0 && info[i] == 0) continue;

            if (ryan[i] > info[i]) {
                ryanScore += score;
            } else {
                apeachScore += score;
            }
        }

        int diff = ryanScore - apeachScore;

        // 이기는 경우만 정답 후보로 인정
        if (diff > 0) {
            if (diff > bestDiff ||
                (diff == bestDiff && preferLower(ryan, answer))) {
                bestDiff = diff;
                answer = ryan;
            }
        }

        ryan[10] = 0;
        return;
    }

    // 이 점수 가져오기
    int need = info[idx] + 1;

    if (remain >= need) {
        ryan[idx] = need;
        dfs(idx + 1, remain - need, info, ryan, answer, bestDiff);
        ryan[idx] = 0;
    }

    // 이 점수 포기하기
    dfs(idx + 1, remain, info, ryan, answer, bestDiff);
}

vector<int> solution(int n, vector<int> info) {
    vector<int> ryan(11, 0);
    vector<int> answer(11, 0);
    int bestDiff = 0;

    dfs(0, n, info, ryan, answer, bestDiff);

    if (bestDiff == 0) return {-1};
    return answer;
}
```

## 다시 풀 때 생각할 순서

1. 배열 인덱스와 실제 점수의 관계를 정리한다.
2. 각 구간을 이기는 데 필요한 최소 화살 수를 구한다.
3. 가져오기 / 포기하기로 선택을 나눈다.
4. 0점 구간에서 남은 화살을 처리한다.
5. 점수 차이가 양수인지 확인한다.
6. 최대 차이를 갱신하고, 차이가 같으면 낮은 점수부터 비교한다.
