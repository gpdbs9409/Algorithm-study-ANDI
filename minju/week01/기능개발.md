## 42586 기능 개발

코딩테스트 연습 - 기능개발

처음에 당황하긴 했는데 좀 더 생각해보면 됨. 그 하나 틀려서

`period.push_back((100 - progresses[i]) / speeds[i]);` 너무 단순히 생각했었나봄..

남은 량을 하루 작업 속도로 나누면 될 거라고 생각했는데, 나머지가 남는 날에 하루를 적게 계산하게 되어서 틀림.

```
for(int i=0; i<progresses.size(); i++){
     period.push_back((100 - progresses[i] + speeds[i] - 1) / speeds[i]);
}
```

이렇게 고쳤는데 이것도 나중에 다시 풀어보면 좋을듯

- 코드

  ```bash
  #include <string>
  #include <vector>
  #include <bits/stdc++.h>
  using namespace std;

  vector<int> solution(vector<int> progresses, vector<int> speeds) {
      vector<int> answer;

      vector<int> period;
      for(int i=0; i<progresses.size(); i++){
           period.push_back((100 - progresses[i] + speeds[i] - 1) / speeds[i]);
      }
      for(int r : period){
          cout << r << " ";
      }
      int maxx = period[0];
      int count = 1;
      for(int i=1; i<period.size(); i++){
          if(maxx < period[i]){
              answer.push_back(count);
              count = 0;
              maxx = period[i];
          }
          count++;
      }
      answer.push_back(count);
      return answer;
  }
  ```
