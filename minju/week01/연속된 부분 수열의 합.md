## 연속된 부분 수열의 합

코딩테스트 연습 - 연속된 부분 수열의 합

다 까먹음… 일단 vector에는 length() 함수 존재 안해서 size 고를 때 size() 서야 하는 거.

**투포인터를 떠올릴 수 있는 아이디어**

**연속 → 시작점과 끝점을 조절할 수 있는 문제의 힌트가 되니까 슬라이딩윈도우나 투포인터를 떠올릴 수 있음**

투포인터 구조

1. 오른쪽 포인터 이동시키기 2) 왼쪽 포인터 이동하면서 조건 맞는지 찾기 3) 정답이면 최솟값이나 최댓값 값 바꾸기

`sum > k` 목표보다 커졌으니까 줄이자!

`sum == k` 딱 맞네 정답 갱신하자!!

- 코드

  ```sql
  #include <bits/stdc++.h>
  using namespace std;

  vector<int> solution(vector<int> sequence, int k) {
      int n = sequence.size();
      int l = 0;
      int sum = 0;
      int ll = 0;
      int rr = n;
      int min = 1000000001;

      for(int r = 0; r < n; r++){
          sum += sequence[r];
          while(sum > k && l <= r){
              sum -= sequence[l];
              l++;
          }
          if(sum == k){
              int length = r - l + 1;
              if(length < min){
                  min = length;
                  ll = l;
                  rr = r;
              }
          }
      }

      return {ll, rr};
  }
  ```
