- 문제: 코딩테스트 연습 - 타겟 넘버
- 풀이 코드

  ```cpp
  #include <bits/stdc++.h>
  using namespace std;
  int answer;

  void dfs(vector<int> numbers, int target, int idx, int sum){
      if(idx == numbers.size()){
          if(sum == target){
              answer++;
          }
          return;
      }
      // +
      dfs(numbers, target, idx + 1, sum + numbers[idx]);
      // -
      dfs(numbers, target, idx + 1, sum - numbers[idx]);
  }

  int solution(vector<int> numbers, int target) {
      answer = 0;
      dfs(numbers, target, 0, 0);
      return answer;
  }
  ```

- 참고
  - 전역 변수로 `answer`를 선언해야 재귀 호출되는 dfs 함수와 값을 공유할 수 있음.
  - 종료 조건: `idx == numbers.size()`가 되면 `sum == target`일 때 `answer`를 증가시키고 바로 `return`.

- DFS/BFS 정리
  - 문제 풀이 사고 순서
    1. 무엇을 탐색해야 하는가 — 노드, 격자 칸, 가능한 선택 조합인지 판단
    2. 현재 상태를 어떤 변수로 표현할 것인가 — `node`, `(x, y)`, `(idx, sum)` 등
    3. 현재 상태에서 다음으로 어떻게 이동하는가 — 인접 노드, 상하좌우, 더하기/빼기 등
    4. 언제 탐색을 종료하는가 — 더 갈 곳이 없거나, 목적지에 도착하거나, 모든 선택을 마쳤을 때
    5. 방문 체크가 필요한가 — 같은 상태를 반복 방문할 수 있는지 확인
    6. DFS와 BFS 중 어느 쪽이 적합한가 — 모든 경우를 탐색하는지, 최단거리를 구하는지로 판단

  - DFS vs BFS 선택 기준

    | 문제 조건 | 우선 고려할 방법 |
    | --- | --- |
    | 연결된 영역의 개수 구하기 | DFS 또는 BFS |
    | 모든 가능한 조합 탐색 | DFS / 백트래킹 |
    | 최단거리 구하기 (모든 이동 비용이 동일) | BFS |
    | 최소 이동 횟수 구하기 | BFS |
    | 모든 경로를 끝까지 탐색 | DFS |
    | 그래프에 사이클이 있는 경우 | DFS/BFS + 방문 관리 |

  - 매개변수 전달 방식
    - `void dfs(vector<int> numbers, ...)` — 호출할 때마다 벡터 전체를 복사하게 되어 비효율적.
    - `void dfs(vector<int>& numbers, ...)` — 참조로 받아 복사 없이 원본을 사용. 재귀 호출이 많은 dfs에서 특히 중요.
    - `void dfs(const vector<int>& numbers, ...)` — `const`로 원본을 수정하지 못하게 막음. numbers를 읽기만 할 때 사용.
    - tip: `int`처럼 복사 비용이 작은 타입은 보통 `&`를 붙이지 않지만, `vector`/`string`처럼 커질 수 있는 타입은 읽기만 할 때 `const &`로 전달하는 패턴을 자주 씀.

  - DFS 기본 틀 (재귀함수)

    ```cpp
    #include <vector>
    using namespace std;

    vector<vector<int>> graph;
    vector<bool> visited;

    void dfs(int node) {
        visited[node] = true;

        for (int next : graph[node]) {
            if (!visited[next]) {
                dfs(next);
            }
        }
    }
    ```

    핵심 구조
    1. `visited[node] = true` — 현재 노드 방문 처리
    2. `for` — 연결된 노드 확인
    3. `if (!visited[next])` — 방문하지 않았다면
    4. `dfs(next)` — 재귀 호출로 다음 노드 탐색

  - BFS 기본 틀 (Queue)

    ```cpp
    #include <vector>
    #include <queue>
    using namespace std;

    vector<vector<int>> graph;
    vector<bool> visited;

    void bfs(int start) {
        queue<int> q;
        q.push(start);
        visited[start] = true;

        while (!q.empty()) {
            int node = q.front();
            q.pop();

            for (int next : graph[node]) {
                if (!visited[next]) {
                    visited[next] = true;
                    q.push(next);
                }
            }
        }
    }
    ```

    핵심 구조
    1. `queue<int> q` — 큐 생성
    2. `q.push(start)` — 시작 노드 삽입
    3. `while (!q.empty())` — 큐가 빌 때까지 탐색
    4. `q.front()` / `q.pop()` — 현재 노드 꺼내기
    5. `visited[next] = true` / `q.push(next)` — 다음 노드 방문 예약

  - DFS vs BFS 기본 코드 비교

    | DFS | BFS |
    | --- | --- |
    | 재귀함수 | queue |
    | 깊이 우선 탐색 | 너비 우선 탐색 |
    | `dfs(next)` | `q.push(next)` |
    | 호출 스택 이용 | 큐 이용 |
    | 방문 시점에 `visited` 처리 | 큐에 넣을 때 `visited` 처리 |
