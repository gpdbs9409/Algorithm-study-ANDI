- 문제: 코딩테스트 연습 - 네트워크
- 풀이 코드

  ```cpp
  #include <string>
  #include <vector>
  using namespace std;

  void dfs(int v, int n,
           const vector<vector<int>>& computers,
           vector<bool>& visited) {
      visited[v] = true;

      for (int i = 0; i < n; i++) {

          if (computers[v][i] == 1 && !visited[i]) {

              dfs(i, n, computers, visited);
          }
      }
  }

  int solution(int n, vector<vector<int>> computers) {
      int answer = 0;
      vector<bool> visited(n, false);


      for (int i = 0; i < n; i++) {
          if (!visited[i]) {

              dfs(i, n, computers, visited);

              answer++;
          }
      }

      return answer;
  }
  ```

- 설명
  - `visited` 배열과 연결 여부를 나타내는 `computers` 배열을 사용. `computers[i][j]`는 i번 컴퓨터와 j번 컴퓨터의 연결 여부.
  - 아직 방문하지 않은 컴퓨터를 발견하면 dfs를 실행해 연결된 모든 컴퓨터를 방문 처리하고, dfs가 끝나면 `answer`를 하나 증가시킨다. 다음 컴퓨터로 넘어갈 때 이미 방문했다면 스킵.
  - 흐름: 미방문 컴퓨터 발견 → DFS 시작 → 현재 컴퓨터 방문 처리 → 연결된 미방문 컴퓨터를 재귀적으로 탐색 → DFS 종료 → 네트워크 개수 증가 → 다음 미방문 컴퓨터 탐색.
  - `dfs()`는 연결된 컴퓨터를 모두 방문하는 역할이고, `solution()`은 DFS를 새로 시작하는 횟수(=네트워크 개수)를 세는 역할로 구분된다.
