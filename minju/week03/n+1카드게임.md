- 문제: n+1 카드게임 (2024, Lv.3)
- 조건 / 복잡도
  - 매 라운드마다 최대 n개의 숫자를 확인하고, 라운드 수는 최대 n/3개이므로 시간 복잡도는 O(n²).
  - n이 1000 이하면 통과 가능.
- 그리디로 접근
  - 카드를 무작정 버리면 나중에 필요한 카드를 잃어버릴 수 있으므로 그리디 알고리즘을 사용.
  1. 새로 등장한 카드를 모두 후보(`pending`)에 기록한다.
  2. 당장 필요한 카드 조합 중 동전이 가장 적게 드는 조합을 사용한다.
  3. 나중에 사용하게 된 후보 카드는 처음 등장했을 때 구매해 두었다고 해석한다.
  4. 최종 동전 사용량이 초기 동전 수를 넘지 않도록 관리한다.
  - 나중에 필요할 카드를 미리 버리지 않기 위해 `pending`이라는 후보 배열을 둔다.
- 매칭 로직 (동전 0개로 짝 맞추는 경우)
  1. 1번 카드부터 확인한다.
  2. 그 카드와 합쳐서 n+1이 되는 짝을 계산한다.
  3. 두 카드를 모두 가지고 있는지 확인한다.
  4. 모두 있으면 제출하고 보유 카드 목록에서 제거한다.
  5. 이번 라운드를 성공으로 표시하고 반복문을 종료한다.
- 풀이 코드

  ```cpp
  #include <vector>
  using namespace std;

  int solution(int coin, vector<int> cards) {
      int n = cards.size();
      int answer = 1;

      vector<bool> hand(n + 1, false);
      vector<bool> pending(n + 1, false);

      for (int i = 0; i < n / 3; i++) {
          hand[cards[i]] = true;
      }

      for (int i = n / 3; i < n; i += 2) {
          pending[cards[i]] = true;
          pending[cards[i + 1]] = true;

          bool success = false;

          // 동전 0개
          for (int j = 1; j <= n / 2; j++) {
              int other = n + 1 - j;

              if (hand[j] && hand[other]) {
                  hand[j] = false;
                  hand[other] = false;

                  success = true;
                  break;
              }
          }

          // 동전 1개
          if (!success && coin >= 1) {
              for (int j = 1; j <= n; j++) {
                  int other = n + 1 - j;

                  if (hand[j] && pending[other]) {
                      hand[j] = false;
                      pending[other] = false;

                      coin--;
                      success = true;
                      break;
                  }
              }
          }

          // 동전 2개
          if (!success && coin >= 2) {
              for (int j = 1; j <= n / 2; j++) {
                  int other = n + 1 - j;

                  if (pending[j] && pending[other]) {
                      pending[j] = false;
                      pending[other] = false;

                      coin -= 2;
                      success = true;
                      break;
                  }
              }
          }

          if (!success) {
              break;
          }

          answer++;
      }

      return answer;
  }
  ```
