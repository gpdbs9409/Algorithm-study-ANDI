나머지 연산(모듈러 연산)에는 덧셈에 대한 분배 법칙이 성립.

$$(A + B) \bmod M = ((A \bmod M) + (B \bmod M)) \bmod M$$

"다 더한 뒤에 마지막에 한 번만 나누는 것"과 "매 단계마다 미리 나눈 나머지를 가지고 다음 계산을 하는 것"은 일치

피보나치 구하면서 나머지 연산 진행하고, 다음 계산을 위해 숫자들을 한 칸씩 밀면 됨

```
int solution(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;

    int prev2 = 0;
    int prev1 = 1;
    int current = 0;

    for (int i = 2; i <= n; i++) {
        current = (prev1 + prev2) % 1234567; // 앞의 두 숫자를 더하고 나머지 구하기


        prev2 = prev1;
        prev1 = current;
    }

    return current;
}
```
