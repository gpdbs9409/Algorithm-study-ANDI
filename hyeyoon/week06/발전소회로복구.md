
# 발전소 회로 복구 - 프로그래머스

## 문제

- h층으로 이루어진 발전소가 존재한다.
- 모든 층은 동일한 n × m 격자 구조를 가진다.
- `.` : 이동 가능한 통로
- `#` : 이동 불가능한 벽
- `@` : 엘리베이터
- 상하좌우 이동에는 1초가 걸린다.
- 층수 이동에는 abs(현재 층 - 다음 층)만큼의 시간이 걸린다.
- 기술자는 1번 패널의 위치에서 출발한다.
- 모든 패널은 처음에 비활성화 상태이다.
- 안전 순서 [a, b]는 a번 패널을 활성화해야 b번 패널을 활성화할 수 있다는 의미이다.

모든 패널을 안전하게 활성화하는 데 필요한 최소 시간을 구한다.

### 제한사항

- 1 ≤ h ≤ 10
- 2 ≤ n, m ≤ 40
- 2 ≤ k ≤ 15 (패널 개수)
- 1 ≤ len(seqs) ≤ 100

## 접근방법

### 1. 나의 초기 접근

문제를 한 번에 해결하기보다 필요한 기능을 나누어서 구현하려고 했다.

먼저 다음과 같은 변수를 선언했다.

```python
if_pushed = [False] * (k + 1)

now_floor = 0
now_locations = (0, 0)

elevate_locations = []
panel_locations = []
```

- if_pushed : 각 패널의 활성화 여부
- now_floor : 현재 층수
- now_locations : 현재 위치
- elevate_locations : 엘리베이터 위치
- panel_locations : 패널 위치

이후 전체적인 실행 흐름을 다음과 같이 구성했다.

1. 시작 지점과 엘리베이터 위치 찾기
2. 현재 활성화할 수 있는 패널 확인하기
3. 현재 위치에서 엘리베이터까지 이동하기
4. 엘리베이터로 층수 이동하기
5. 엘리베이터에서 패널까지 이동하기

모든 패널이 활성화될 때까지 위 과정을 반복하려고 했다.

```python
while not all(if_pushed):
```

### 2. 초기 접근에서 잘한 점

- 패널의 활성화 여부를 Boolean 배열로 관리하려고 했다.
- 현재 위치를 층수와 평면 좌표로 분리했다.
- 엘리베이터 위치를 미리 찾아 저장하려고 했다.
- 안전 순서를 반복문으로 검사하려고 했다.
- 층수 이동 시간을 절댓값으로 정확하게 계산했다.
- 평면 이동과 층수 이동을 분리했다.
- 최단 경로를 구하는 함수를 별도로 선언하고 재사용하려고 했다.

특히 #3과 #5에서 동일한 find_route() 함수를
재사용하려고 한 접근이 좋았다.

문제를 기능 단위로 분해하는 방향은 맞았다.

### 3. 초기 접근에서 부족했던 점

#### (1) 패널 활성화 조건

처음에는 다음과 같이 작성했다.

```python
for pair in seqs:
    if pair[0] == panel and pair[1] == True:
        if_pushed[panel] = True
```

하지만 pair[1]은 Boolean이 아니라 패널 번호이다.

또한 [a, b]는 a번 패널을 먼저 활성화해야
b번 패널을 활성화할 수 있다는 의미이다.

따라서 현재 활성화하려는 패널이 b라면,
a번 패널의 활성화 여부를 확인해야 한다.

```python
for a, b in seqs:
    if b == panel and not if_pushed[a]:
        return False
```

선행 조건이 여러 개 존재한다면 모든 조건을
만족해야 한다.

선행 조건이 없는 패널은 반복문을 통과하므로
별도의 조건문을 작성할 필요가 없다.

#### (2) BFS 구현

처음에는 현재 위치에서 상하좌우로 이동하면서
시간을 증가시키려고 했다.

```python
for i in range(4):
    nx = now[0] + dx[i]
    ny = now[1] + dy[i]

    if grid[nx][ny] == '.':
        time += 1
```

하지만 이 방식은 현재 위치에서 인접한 네 칸만
확인할 뿐, 목적지까지의 최단 거리를 구할 수 없다.

격자에서 모든 이동 비용이 1이므로 BFS를 사용한다.

BFS는 출발점에서 가까운 위치부터 탐색하기 때문에
처음 목적지에 도착했을 때의 이동 시간이 최단 거리이다.

큐에는 좌표와 해당 좌표까지의 이동 시간을 함께 저장한다.

```python
queue = deque([(start[0], start[1], 0)])
```

큐에서 꺼낼 때는 pop()이 아니라 popleft()를 사용한다.

```python
x, y, time = queue.popleft()
```

다음 칸을 큐에 추가할 때 이동 시간을 증가시킨다.

```python
queue.append((nx, ny, time + 1))
```

time += 1로 전체 시간을 증가시키면 안 된다.
각 탐색 경로마다 이동 시간이 다르기 때문이다.

#### (3) 함수의 인자가 많아지는 문제

처음에는 BFS 함수를 solution() 외부에 선언하려고 했다.

```python
def find_route(start, end, n, m, grid):
```

하지만 필요한 인자가 많아지는 문제가 있었다.

solution() 내부에 함수를 선언하면 바깥 함수의
변수를 읽을 수 있다.

```python
def solution(h, grid, panels, seqs):
    n = len(grid)
    m = len(grid[0])

    def find_route(start, end):
        visited = [[False] * m for _ in range(n)]
```

이를 렉시컬 스코프라고 한다.

따라서 호출할 때마다 달라지는 start와 end만
인자로 전달하면 된다.

#### (4) 패널 활성화 순서

처음에는 활성화 가능한 패널을 찾으면
바로 활성화하려고 했다.

하지만 활성화 가능한 패널이 여러 개라면
어떤 패널을 먼저 선택하는지에 따라
전체 이동 시간이 달라진다.

예를 들어 안전 순서가 다음과 같다면,

```python
seqs = [[3, 2], [1, 2], [4, 1], [4, 3]]
```

가능한 활성화 순서는 다음과 같다.

- 4 → 1 → 3 → 2
- 4 → 3 → 1 → 2

따라서 단순 반복문이나 그리디 방식으로
패널을 선택하면 최솟값이 보장되지 않는다.

가능한 활성화 순서를 DFS와 백트래킹으로 탐색한다.

## sol1. BFS + 백트래킹

### 핵심 아이디어

1. BFS로 패널 사이의 최단 이동 시간을 계산한다.
2. 계산한 이동 시간을 이차원 배열에 저장한다.
3. DFS로 가능한 패널 활성화 순서를 탐색한다.
4. 백트래킹으로 선택한 패널의 활성화 상태를 복구한다.
5. 모든 패널을 활성화했을 때 최소 시간을 갱신한다.

### 전체 코드

```python
from collections import deque

def solution(h, grid, panels, seqs):
    answer = float('inf')

    n = len(grid)
    m = len(grid[0])
    k = len(panels)

    # 패널 활성화 여부
    # 패널 번호가 1부터 시작하므로 k+1개 선언
    if_pushed = [False] * (k + 1)

    panel_locations = []

    # 패널의 행, 열을 0-based 인덱스로 변환
    for f, r, c in panels:
        panel_locations.append((f, r-1, c-1))

    # 1. 엘리베이터 위치 찾기
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '@':
                elevate_location = (i, j)

    # 같은 층에서 최단 이동 시간을 구하는 BFS
    def find_route(start, end):

        dx = [0, 0, 1, -1]
        dy = [1, -1, 0, 0]

        # (현재 x좌표, 현재 y좌표, 이동 시간)
        queue = deque([(start[0], start[1], 0)])

        visited = [[False] * m for _ in range(n)]
        visited[start[0]][start[1]] = True

        while queue:

            x, y, time = queue.popleft()

            # 목적지에 도착하면 최단 시간 반환
            if (x, y) == end:
                return time

            # 상하좌우 탐색
            for i in range(4):
                nx = x + dx[i]
                ny = y + dy[i]

                # 격자 범위 확인
                if 0 <= nx < n and 0 <= ny < m:

                    # 벽이 아니고 방문하지 않았다면 이동
                    if grid[nx][ny] != '#' and not visited[nx][ny]:

                        visited[nx][ny] = True
                        queue.append((nx, ny, time + 1))

        return float('inf')

    # 2. 패널을 활성화할 수 있는지 확인
    def check_panel(panel):

        # 이미 활성화한 패널이면 제외
        if if_pushed[panel]:
            return False

        # 선행 패널의 활성화 여부 확인
        for a, b in seqs:
            if b == panel and not if_pushed[a]:
                return False

        return True

    # 패널 간 이동 시간을 구하는 함수
    def move(start_panel, end_panel):

        now_floor, x, y = panel_locations[start_panel - 1]
        now_locations = (x, y)

        next_floor, px, py = panel_locations[end_panel - 1]
        next_location = (px, py)

        time = 0

        # 다른 층으로 이동하는 경우
        if now_floor != next_floor:

            # 3. 현재 위치 → 엘리베이터
            time += find_route(now_locations, elevate_location)

            # 4. 층수 이동
            time += abs(now_floor - next_floor)

            now_locations = elevate_location

        # 5. 현재 위치 → 다음 패널
        time += find_route(now_locations, next_location)

        return time

    # 패널 간 이동 시간 전처리
    distances = [[0] * (k + 1) for _ in range(k + 1)]

    for i in range(1, k + 1):
        for j in range(i + 1, k + 1):

            distances[i][j] = move(i, j)

            # 반대 방향의 이동 시간도 동일
            distances[j][i] = distances[i][j]

    # 6. DFS + 백트래킹
    def dfs(now_panel, total_time):

        nonlocal answer

        # 가지치기
        # 현재까지의 시간이 이미 최솟값 이상이면 종료
        if total_time >= answer:
            return

        # 모든 패널을 활성화했다면 최솟값 갱신
        if all(if_pushed[1:]):
            answer = min(answer, total_time)
            return

        # 활성화 가능한 모든 패널 탐색
        for panel in range(1, k + 1):

            if check_panel(panel):

                # 전처리한 이동 시간 가져오기
                time = distances[now_panel][panel]

                # 선택
                if_pushed[panel] = True

                # 다음 패널 탐색
                dfs(panel, total_time + time)

                # 선택 취소
                if_pushed[panel] = False

    # 1번 패널 위치에서 출발
    # 아직 1번 패널도 활성화되지 않은 상태
    dfs(1, 0)

    return answer
```

### 핵심 개념 1. 거리 전처리

백트래킹을 수행하면 동일한 패널 사이의 이동 시간을
반복해서 계산하게 된다.

하지만 패널 사이의 이동 시간은 항상 동일하다.

따라서 DFS를 실행하기 전에 모든 패널 사이의
이동 시간을 미리 계산한다.

```python
distances = [[0] * (k + 1) for _ in range(k + 1)]
```

distances[i][j]는 i번 패널에서 j번 패널까지의
최단 이동 시간을 의미한다.

패널 번호를 그대로 인덱스로 사용하기 위해
0번 행과 열은 사용하지 않는다.

```python
for i in range(1, k + 1):
    for j in range(i + 1, k + 1):
        distances[i][j] = move(i, j)
        distances[j][i] = distances[i][j]
```

패널이 4개라면 다음 순서로 반복문이 실행된다.

| i | j | 계산하는 거리 |
|---|---|---|
| 1 | 2 | 1번 ↔ 2번 |
| 1 | 3 | 1번 ↔ 3번 |
| 1 | 4 | 1번 ↔ 4번 |
| 2 | 3 | 2번 ↔ 3번 |
| 2 | 4 | 2번 ↔ 4번 |
| 3 | 4 | 3번 ↔ 4번 |

이동 시간은 양방향이 동일하므로 한 번만 계산한다.

예를 들어 문제의 첫 번째 예시에서,

```python
distances[1][4] = move(1, 4)
```

1번 패널에서 4번 패널까지 이동하는 시간은

- 현재 위치 → 엘리베이터 : 4초
- 2층 → 3층 : 1초
- 엘리베이터 → 4번 패널 : 2초

총 7초이다.

```python
distances[1][4] = 7
distances[4][1] = 7
```

이후 DFS에서는 BFS를 다시 호출하지 않고
배열에서 값을 가져오기만 하면 된다.

```python
time = distances[now_panel][panel]
```

전처리란 반복해서 사용할 계산 결과를
미리 구해서 저장해 놓는 것이다.

### 핵심 개념 2. 백트래킹

DFS를 사용해 가능한 패널 활성화 순서를 탐색한다.

기존의 while 반복문은 하나의 활성화 순서만
탐색할 수 있었다.

백트래킹을 사용하면 여러 활성화 순서를
모두 탐색할 수 있다.

예를 들어,

```text
             시작
               |
               4
             /   \
            1     3
            |     |
            3     1
            |     |
            2     2
```

첫 번째 경로를 끝까지 탐색한 후,
이전 상태로 돌아가 두 번째 경로를 탐색한다.

백트래킹의 핵심은 다음 세 줄이다.

```python
if_pushed[panel] = True

dfs(panel, total_time + time)

if_pushed[panel] = False
```

1. 현재 패널을 선택한다.
2. 선택한 상태에서 다음 패널을 탐색한다.
3. 탐색이 끝나면 선택을 취소한다.

선택을 취소해야 다른 활성화 순서도 탐색할 수 있다.

#### DFS의 인자

```python
def dfs(now_panel, total_time):
```

- now_panel : 현재 위치한 패널 번호
- total_time : 현재까지 누적된 이동 시간

패널 번호를 알면 해당 패널의 층수와 좌표를
알 수 있으므로 층수와 좌표를 별도로 전달할 필요가 없다.

또한 패널 사이의 이동 시간을 전처리했으므로
DFS에서는 층수와 좌표를 직접 사용할 필요도 없다.

#### 가지치기

```python
if total_time >= answer:
    return
```

이동 시간은 음수가 될 수 없다.

따라서 현재까지의 이동 시간이 이미 구한 최솟값보다
크거나 같다면 이후 탐색을 진행할 필요가 없다.

불필요한 탐색을 중단하는 것을 가지치기라고 한다.

### 핵심 개념 3. 함수의 실행 순서

def는 함수를 정의하는 문법이다.
함수 내부 코드는 해당 함수를 호출할 때 실행된다.

전체 함수는 총 5개이다.

- solution()
- find_route()
- check_panel()
- move()
- dfs()

실제 실행 순서는 다음과 같다.

```text
solution() 실행
    |
    |-- 변수 선언 및 패널 위치 저장
    |-- 엘리베이터 위치 찾기
    |
    |-- find_route() 정의
    |-- check_panel() 정의
    |-- move() 정의
    |
    |-- 거리 전처리 반복문 실행
    |       |
    |       |-- move() 호출
    |               |
    |               |-- find_route() 호출
    |
    |-- dfs() 정의
    |
    |-- dfs(1, 0) 호출
    |       |
    |       |-- check_panel() 호출
    |       |-- dfs() 재귀 호출
    |       |-- 백트래킹
    |
    |-- return answer
```

결국 메인 실행 로직은 크게 두 부분이다.

1. BFS를 이용한 거리 전처리
2. DFS를 이용한 최소 이동 시간 탐색

나머지 함수들은 위 두 작업을 수행하기 위한
보조 함수이다.

---

### 핵심 개념 4. nonlocal

```python
def dfs(now_panel, total_time):
    nonlocal answer
```

함수 내부에서 바깥 함수의 변수에 접근할 수 있다.

하지만 바깥 함수의 변수에 새로운 값을 할당하려면
nonlocal을 선언해야 한다.

```python
answer = min(answer, total_time)
```

반면 리스트의 내부 원소만 수정하는 경우에는
nonlocal을 선언할 필요가 없다.

```python
if_pushed[panel] = True
```

## 시간복잡도

n : 격자의 행 개수
m : 격자의 열 개수
k : 패널 개수
s : 안전 순서 쌍의 개수

### 1. 엘리베이터 위치 찾기

격자의 모든 칸을 확인한다.

시간복잡도 : O(nm)

### 2. BFS

각 격자 칸을 최대 한 번씩 방문한다.

각 칸에서 상하좌우 4방향을 확인한다.

시간복잡도 : O(nm)

### 3. 패널 간 이동 시간 전처리

패널 사이의 모든 조합을 확인한다.

패널이 k개라면 서로 다른 패널 쌍의 개수는

k(k-1) / 2

따라서 패널 쌍의 개수는 O(k²)이다.

move()에서는 같은 층이면 BFS를 1번,
다른 층이면 BFS를 2번 실행한다.

BFS 실행 횟수 1 또는 2는 상수이므로

시간복잡도 : O(k² × nm)

### 4. DFS + 백트래킹

안전 순서에 의한 제약이 거의 없다면
가능한 패널 활성화 순서의 개수는
최악의 경우 팩토리얼 규모로 증가한다.

전체 DFS 호출 횟수의 상한은 O(k!)이다.

각 DFS 호출에서는

- all(if_pushed[1:]) 검사 : O(k)
- 패널 후보 반복 : O(k)
- check_panel()의 안전 순서 검사 : O(s)

따라서 각 DFS 호출의 시간복잡도 상한은

O(k + ks) = O(k(s+1))

전체 DFS 시간복잡도의 보수적인 상한은

O(k(s+1) × k!)

이다.

### 전체 시간복잡도

O(k²nm + k(s+1)k!)

실제로는 안전 순서 제약과 가지치기 때문에
탐색 횟수가 줄어들 수 있다.

그러나 최악의 경우 팩토리얼 규모로 증가하므로
패널이 15개라면 시간 초과가 발생할 수 있다.

15! = 1,307,674,368,000

안전 순서가 최소 하나 존재하므로 실제 가능한
순서의 수는 이보다 적지만, 여전히 매우 크다.

## 공간복잡도

### 1. BFS 방문 배열

```python
visited = [[False] * m for _ in range(n)]
```

공간복잡도 : O(nm)

### 2. BFS 큐

최대 nm개의 격자 칸을 저장할 수 있다.

공간복잡도 : O(nm)

### 3. 거리 전처리 배열

```python
distances = [[0] * (k + 1) for _ in range(k + 1)]
```

공간복잡도 : O(k²)

### 4. 패널 위치 및 활성화 배열

```python
panel_locations = []
if_pushed = [False] * (k + 1)
```

공간복잡도 : O(k)

### 5. DFS 재귀 호출 스택

패널을 한 개씩 활성화하므로 최대 재귀 깊이는 k이다.

공간복잡도 : O(k)

### 전체 공간복잡도

보조 공간 기준:

O(nm + k² + k)

정리하면:

O(nm + k²)

입력으로 주어진 안전 순서 배열까지 포함하면

O(nm + k² + s)

BFS는 거리 전처리 단계에서 실행되며,
DFS 내부에서는 다시 실행하지 않는다.

따라서 재귀 깊이마다 BFS 방문 배열을
새로 유지하는 구조가 아니다.

## sol2. 추후 최적화 방향

현재 풀이의 문제점은 DFS에서 동일한 상태를
반복해서 탐색할 수 있다는 것이다.

예를 들어 다음 두 경로가 존재한다고 가정한다.

- 1 → 2 → 3
- 2 → 1 → 3

두 경로는 현재 위치가 3번 패널이고,
활성화한 패널의 집합도 동일하다.

이 상태에 도달한 시간이 더 짧은 경로만
유지하면 불필요한 탐색을 줄일 수 있다.

이를 메모이제이션으로 최적화할 수 있다.

추후 학습할 개념:

- 메모이제이션
- DP
- 비트마스킹 DP

비트마스킹 DP를 사용하면 활성화된 패널의 집합과
현재 패널 번호를 하나의 상태로 관리할 수 있다.

현재는 BFS와 백트래킹의 구현에 집중한다.
