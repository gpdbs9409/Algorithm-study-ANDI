
# 발전소 회로 복구 - 프로그래머스

## 문제

https://school.programmers.co.kr/learn/courses/30/lessons/468375


- h층으로 이루어진 발전소가 존재한다.
- 모든 층은 동일한 n × m 격자 구조를 가진다.
- `.` : 이동 가능한 통로
- `#` : 이동 불가능한 벽
- `@` : 엘리베이터
- 상하좌우 이동에는 1초가 걸린다.
- 층수 이동에는 abs(현재 층 - 다음 층)만큼의 시간이 걸린다.
- 기술자는 1번 패널의 위치에서 출발한다.
- 모든 패널은 처음에 비활성화 상태이다.
- 안전 순서 [a, b]는 a번 패널을 활성화해야 b번 패널을 활성화할 수 있다는 의미이다.

모든 패널을 안전하게 활성화하는 데 필요한 최소 시간을 구한다.

### 제한사항

- 1 ≤ h ≤ 10
- 2 ≤ n, m ≤ 40
- 2 ≤ k ≤ 15 (패널 개수)
- 1 ≤ len(seqs) ≤ 100 [[3, 2], [1, 2], [4, 1], [4, 3]]

## 접근방법

### 1. 나의 초기 접근

문제를 한 번에 해결하기보다 필요한 기능을 나누어서 구현하려고 했다.

먼저 다음과 같은 변수를 선언했다.

```python
if_pushed = [False] * (k + 1)

now_floor = 0
now_locations = (0, 0)

elevate_locations = []

```

- if_pushed : 각 패널의 활성화 여부
- now_floor : 현재 층수
- now_locations : 현재 위치
- elevate_locations : 엘리베이터 위치

이후 전체적인 실행 흐름을 다음과 같이 구성했다.

1. 시작 지점과 엘리베이터 위치 찾기
2. 현재 활성화할 수 있는 패널 확인하기
3. 현재 위치에서 엘리베이터까지 이동하기
4. 엘리베이터로 층수 이동하기
5. 엘리베이터에서 패널까지 이동하기

모든 패널이 활성화될 때까지 위 과정을 반복하려고 했다.

```python
while not all(if_pushed):
```

- 엘리베이터 위치를 미리 찾아 저장하려고 했다.

  for pair in seqs:

### 3. 초기 접근에서 부족했던 점

#### (1) distance 


distnace를 미리 구해놓으면 1->3 3->1이 동일하므로 두번 계산을 하지 않아도된다는 점을 까먹었다. 

#### (2) 패널 활성화 순서

처음에는 활성화 가능한 패널을 찾으면
바로 활성화하려고 했다.

하지만 활성화 가능한 패널이 여러 개라면
어떤 패널을 먼저 선택하는지에 따라
전체 이동 시간이 달라진다.

예를 들어 안전 순서가 다음과 같다면,

```python
seqs = [[3, 2], [1, 2], [4, 1], [4, 3]]
```

가능한 활성화 순서는 다음과 같다.

- 4 → 1 → 3 → 2
- 4 → 3 → 1 → 2

따라서 단순 반복문이나 그리디 방식으로
패널을 선택하면 최솟값이 보장되지 않는다.

가능한 활성화 순서를 DFS와 백트래킹으로 탐색한다.

## sol1. BFS + 백트래킹

### 핵심 아이디어

1. BFS로 패널 사이의 최단 이동 시간을 계산한다.
2. 계산한 이동 시간을 이차원 배열에 저장한다.
3. DFS+백트래킹으로 가능한 패널 활성화 순서를 탐색한다.
4. 모든 패널을 활성화했을 때 최소 시간을 갱신한다.

### 전체 코드

```python
from collections import deque

def solution(h, grid, panels, seqs):
    answer = float('inf')

    n = len(grid)
    m = len(grid[0])
    k = len(panels)

    # 패널 활성화 여부
    # 패널 번호가 1부터 시작하므로 k+1개 선언
    if_pushed = [False] * (k + 1)

    panel_locations = []

    # 패널의 행, 열을 0-based 인덱스로 변환
    for f, r, c in panels:
        panel_locations.append((f, r-1, c-1))

    # 1. 엘리베이터 위치 찾기
    for i in range(n):
        for j in range(m):
            if grid[i][j] == '@':
                elevate_location = (i, j)

    # 같은 층에서 최단 이동 시간을 구하는 BFS
    def find_route(start, end):

        dx = [0, 0, 1, -1]
        dy = [1, -1, 0, 0]

        # (현재 x좌표, 현재 y좌표, 이동 시간)
        queue = deque([(start[0], start[1], 0)])

        visited = [[False] * m for _ in range(n)]
        visited[start[0]][start[1]] = True

        while queue:

            x, y, time = queue.popleft()

            # 목적지에 도착하면 최단 시간 반환
            if (x, y) == end:
                return time

            # 상하좌우 탐색
            for i in range(4):
                nx = x + dx[i]
                ny = y + dy[i]

                # 격자 범위 확인
                if 0 <= nx < n and 0 <= ny < m:

                    # 벽이 아니고 방문하지 않았다면 이동
                    if grid[nx][ny] != '#' and not visited[nx][ny]:

                        visited[nx][ny] = True
                        queue.append((nx, ny, time + 1))

        return float('inf')

    # 2. 패널을 활성화할 수 있는지 확인
    def check_panel(panel):

        # 이미 활성화한 패널이면 제외
        if if_pushed[panel]:
            return False

        # 선행 패널의 활성화 여부 확인
        for a, b in seqs:
            if b == panel and not if_pushed[a]:
                return False

        return True

    # 패널 간 이동 시간을 구하는 함수
    def move(start_panel, end_panel):

        now_floor, x, y = panel_locations[start_panel - 1]
        now_locations = (x, y)

        next_floor, px, py = panel_locations[end_panel - 1]
        next_location = (px, py)

        time = 0

        # 다른 층으로 이동하는 경우
        if now_floor != next_floor:

            # 3. 현재 위치 → 엘리베이터
            time += find_route(now_locations, elevate_location)

            # 4. 층수 이동
            time += abs(now_floor - next_floor)

            now_locations = elevate_location

        # 5. 현재 위치 → 다음 패널
        time += find_route(now_locations, next_location)

        return time

    # 패널 간 이동 시간 전처리
    distances = [[0] * (k + 1) for _ in range(k + 1)]

    for i in range(1, k + 1):
        for j in range(i + 1, k + 1):

            distances[i][j] = move(i, j)

            # 반대 방향의 이동 시간도 동일
            distances[j][i] = distances[i][j]

    # 6. DFS + 백트래킹
    def dfs(now_panel, total_time):

        nonlocal answer

        # 가지치기
        # 현재까지의 시간이 이미 최솟값 이상이면 종료
        if total_time >= answer:
            return

        # 모든 패널을 활성화했다면 최솟값 갱신
        if all(if_pushed[1:]):
            answer = min(answer, total_time)
            return

        # 활성화 가능한 모든 패널 탐색
        for panel in range(1, k + 1):

            if check_panel(panel):

                # 전처리한 이동 시간 가져오기
                time = distances[now_panel][panel]

                # 선택
                if_pushed[panel] = True

                # 다음 패널 탐색
                dfs(panel, total_time + time)

                # 선택 취소
                if_pushed[panel] = False

    # 1번 패널 위치에서 출발
    # 아직 1번 패널도 활성화되지 않은 상태
    dfs(1, 0)

    return answer
```

### 핵심 개념 2. 백트래킹

DFS를 사용해 가능한 패널 활성화 순서를 탐색한다.

기존의 while 반복문은 하나의 활성화 순서만
탐색할 수 있었다.

백트래킹을 사용하면 여러 활성화 순서를
모두 탐색할 수 있다.

예를 들어,

```text
             시작
               |
               4
             /   \
            1     3
            |     |
            3     1
            |     |
            2     2
```

첫 번째 경로를 끝까지 탐색한 후,
이전 상태로 돌아가 두 번째 경로를 탐색한다.

백트래킹의 핵심은 다음 세 줄이다.

```python
if_pushed[panel] = True

dfs(panel, total_time + time)

if_pushed[panel] = False
```

1. 현재 패널을 선택한다.
2. 선택한 상태에서 다음 패널을 탐색한다.
3. 탐색이 끝나면 선택을 취소한다.

선택을 취소해야 다른 활성화 순서도 탐색할 수 있다.

#### DFS의 인자

```python
def dfs(now_panel, total_time):
```

- now_panel : 현재 위치한 패널 번호
- total_time : 현재까지 누적된 이동 시간

패널 번호를 알면 해당 패널의 층수와 좌표를
알 수 있으므로 층수와 좌표를 별도로 전달할 필요가 없다.

또한 패널 사이의 이동 시간을 전처리했으므로
DFS에서는 층수와 좌표를 직접 사용할 필요도 없다.

#### 가지치기

```python
if total_time >= answer:
    return
```

이동 시간은 음수가 될 수 없다.

따라서 현재까지의 이동 시간이 이미 구한 최솟값보다
크거나 같다면 이후 탐색을 진행할 필요가 없다.

불필요한 탐색을 중단하는 것을 가지치기라고 한다.

### 핵심 개념 4. nonlocal

```python
def dfs(now_panel, total_time):
    nonlocal answer
```

함수 내부에서 바깥 함수의 변수에 접근할 수 있다.

하지만 바깥 함수의 변수에 새로운 값을 할당하려면
nonlocal을 선언해야 한다.

```python
answer = min(answer, total_time)
```

반면 리스트의 내부 원소만 수정하는 경우에는
nonlocal을 선언할 필요가 없다.

```python
if_pushed[panel] = True
```

## 시간복잡도

n : 격자의 행 개수
m : 격자의 열 개수
k : 패널 개수
s : 안전 순서 쌍의 개수

### 1. 엘리베이터 위치 찾기

격자의 모든 칸을 확인한다.

시간복잡도 : O(nm)

### 2. BFS

각 격자 칸을 최대 한 번씩 방문한다.

각 칸에서 상하좌우 4방향을 확인한다.

시간복잡도 : O(nm)

### 3. 패널 간 이동 시간 전처리

패널 사이의 모든 조합을 확인한다.

패널이 k개라면 서로 다른 패널 쌍의 개수는

k(k-1) / 2

따라서 패널 쌍의 개수는 O(k²)이다.

move()에서는 같은 층이면 BFS를 1번,
다른 층이면 BFS를 2번 실행한다.

BFS 실행 횟수 1 또는 2는 상수이므로

시간복잡도 : O(k² × nm)

### 4. DFS + 백트래킹

안전 순서에 의한 제약이 거의 없다면
가능한 패널 활성화 순서의 개수는
최악의 경우 팩토리얼 규모로 증가한다.

전체 DFS 호출 횟수의 상한은 O(k!)이다.

각 DFS 호출에서는

- all(if_pushed[1:]) 검사 : O(k)
- 패널 후보 반복 : O(k)
- check_panel()의 안전 순서 검사 : O(s)

따라서 각 DFS 호출의 시간복잡도 상한은

O(k + ks) = O(k(s+1))

전체 DFS 시간복잡도의 보수적인 상한은

O(k(s+1) × k!)

이다.

### 전체 시간복잡도

O(k²nm + k(s+1)k!)
