# 구명보트 (Greedy + Two Pointers)

## 문제

무인도에 갇힌 사람들을 구명보트로 구출하려고 한다.

- 구명보트에는 최대 2명까지 탑승 가능하다.
- 구명보트에는 무게 제한 `limit`가 있다.
- 모든 사람을 구출하는 데 필요한 **구명보트의 최소 개수**를 구해야 한다.

예시:

```python
people = [70, 50, 80, 50]
limit = 100
```

## 문제 접근

일단 가장 무거운 사람과 가장 가벼운 사람을 태워봐야겠다는 생각이 들었다.

따라서 먼저 정렬한다.

가장 무거운 사람은 매번 반드시 보트를 타야 하고, 그 과정에서 가장 가벼운 사람을 함께 태울 수 있는지 확인하면 된다.

즉, **가장 무거운 사람을 기준으로 가장 가벼운 사람과 짝지어 보는 Greedy 방식**이다.

---

## 풀이

### Sol 1. 정렬 + pop()

```python
def solution(people, limit):
    answer = 0
    people.sort()
    print(people)

    while people:
        heavy = people.pop()

        if people and people[0] + heavy <= limit:
            people.pop(0)

        answer += 1

    return answer
```

#### 시간복잡도: O(n²)

- `people.sort()`: O(n log n)
- `people.pop()`: O(1)
- `people.pop(0)`: O(n)

`pop(0)`은 첫 번째 원소를 삭제한 뒤 나머지 원소들을 앞으로 이동시켜야 하므로 O(n)이 걸린다.

이를 반복하면 최악의 경우 O(n²)이 된다.

#### 공간복잡도: O(1)

리스트를 제자리에서 정렬하고 수정하므로 별도의 자료구조를 사용하지 않는다.

※ Python의 정렬 과정에서는 내부적으로 추가 메모리가 사용될 수 있다.

---

### Sol 2. 정렬 + 투포인터 (최종 풀이)

Sol 1에서 `people.pop(0)`이 O(n)의 시간복잡도를 발생시키므로 이를 대체하기 위해 투포인터를 사용했다.

리스트에서 직접 원소를 삭제하는 대신, **인덱스만 이동하면서 처리하는 방식**이다.

```python
def solution(people, limit):
    answer = 0
    left, right = 0, len(people) - 1

    people.sort()

    while left <= right:
        if people[left] + people[right] <= limit and left < right:
            left += 1

        answer += 1
        right -= 1

    return answer
```

#### 핵심 로직

- `left`: 가장 가벼운 사람
- `right`: 가장 무거운 사람
- 두 사람의 무게 합이 `limit` 이하이면 함께 탑승 → `left += 1`
- 가장 무거운 사람은 반드시 탑승 → `right -= 1`
- 보트를 사용할 때마다 `answer += 1`

`left < right` 조건은 한 사람을 두 번 태우지 않기 위한 조건이다.

#### 시간복잡도: O(n log n)

- 정렬: O(n log n)
- 투포인터 순회: O(n)

따라서 전체 시간복잡도는 **O(n log n)** 이다.

정렬 이후의 탐색 과정만 보면 O(n)이다.

#### 공간복잡도: O(1)

별도의 배열 없이 `left`, `right`, `answer` 등의 변수만 사용한다.

※ 정렬 내부의 추가 메모리는 제외한 기준이다.

## 엣지 케이스

| 상황 | 예시 | 결과 |
|---|---|---|
| 사람이 1명 | `[70]`, limit=100 | 1 |
| 두 사람이 함께 탈 수 있음 | `[40, 60]`, limit=100 | 1 |
| 두 사람이 함께 탈 수 없음 | `[70, 80]`, limit=100 | 2 |
| 모든 사람이 같은 무게 | `[50, 50, 50]`, limit=100 | 2 |

## 배운 점


### 빈 배열에 대한 예외 처리

처음에는 다음과 같이 작성했다.

```python
if people[0] + heavy <= limit:
```

그런데 `heavy = people.pop()` 이후 리스트가 비어 있을 수 있어 `IndexError`가 발생했다.

따라서 다음과 같이 수정했다.

```python
if people and people[0] + heavy <= limit:
```

`and`는 앞의 조건이 False이면 뒤의 조건을 검사하지 않는다.

즉, `people`이 비어 있다면 `people[0]`에 접근하지 않으므로 인덱스 오류를 방지할 수 있다.

###  투포인터에서는 연산 순서가 중요하다

Sol 2를 풀 때 일부 테스트케이스가 틀렸는데, 원인은 `right`를 이동시키는 순서였다.

#### 잘못 작성했던 코드

```python
while left <= right:
    right -= 1

    if people[left] + people[right] <= limit and left < right:
        left += 1

    answer += 1
    right -= 1
```

이렇게 `right`를 먼저 감소시키면 가장 무거운 사람을 확인하기도 전에 건너뛰게 된다.

게다가 한 번의 반복에서 `right`가 두 번 감소한다.

#### 올바른 순서

```python
while left <= right:
    if people[left] + people[right] <= limit and left < right:
        left += 1

    answer += 1
    right -= 1
```

**현재 `left`, `right`가 가리키는 사람을 먼저 확인한 다음 포인터를 이동시켜야 한다.**
