# 주사위 고르기

## 문제

A와 B가 n개의 주사위를 가지고 승부를 한다.

- 각 주사위에는 6개의 면이 있으며, 각 면이 나올 확률은 동일하다.
- 주사위에는 1부터 n까지 번호가 부여되어 있다.
- A가 먼저 n/2개의 주사위를 선택한다.
- B는 나머지 n/2개의 주사위를 가져간다.
- 각자 선택한 주사위를 모두 굴린 뒤, 나온 숫자의 합으로 승패를 결정한다.

### 승패 조건

- A의 합 > B의 합 → A 승리
- A의 합 = B의 합 → 무승부
- A의 합 < B의 합 → A 패배

### 목표

A가 승리할 확률이 가장 높아지도록 주사위 n/2개를 선택한다.

선택한 주사위 번호를 **오름차순으로 정렬한 배열**을 반환한다.

승리 확률이 가장 높은 주사위 조합은 유일하다.

### 입출력 예시

n = 4

| 주사위 | 구성 |
|---|---|
| #1 | [1, 2, 3, 4, 5, 6] |
| #2 | [3, 3, 3, 3, 4, 4] |
| #3 | [1, 3, 3, 4, 4, 4] |
| #4 | [1, 1, 4, 4, 5, 5] |

A가 선택한 주사위 조합에 따른 결과는 다음과 같다.

| A의 주사위 | 승 | 무 | 패 |
|---|---:|---:|---:|
| #1, #2 | 596 | 196 | 504 |
| #1, #3 | 560 | 176 | 560 |
| #1, #4 | 616 | 184 | 496 |
| #2, #3 | 496 | 184 | 616 |
| #2, #4 | 560 | 176 | 560 |
| #3, #4 | 504 | 196 | 596 |

따라서 A가 선택해야 하는 주사위는 **[1, 4]** 이다.

## 접근 방법

### 1. A가 선택할 수 있는 주사위 조합 구하기

A는 전체 n개의 주사위 중 n/2개를 선택한다.

따라서 `itertools.combinations`를 이용해 가능한 조합을 구하려고 한다.

```python
from itertools import combinations
```
 A가 선택할 수 있는 주사위 조합을 구한다.

```python
choices = list(combitations(range(n), n//2))

```
또한,위의 choices는 몇번 주사위인지는 알수있지만, 몇 번 주사위에 어떤 숫자가 있는지는 알수없는 배열이므로 어떤 숫자가 있는지까지 알 수있는 배열을 추가한다. 

dice_a=[dice[i] for i in choices]


### 2. A의 선택에 따라 B의 주사위 결정하기

A가 주사위를 선택하면 B는 나머지 주사위를 가져간다.

```python
b_choice =[ i for i in range(n) if i not in choice]
```

b choice또한 dice배열로 풀어준다.

### 3. 각 주사위를 굴렸을 때 가능한 합 구하기

A가 선택한 주사위를 모두 굴렸을 때 나올 수 있는 경우의 수는 다음과 같다.

`6 ** (n/2)`

### 4. A와 B의 합을 비교하여 승패 계산하기

A와 B가 만들 수 있는 합을 각각 구했으므로, 두 배열의 모든 원소를 비교한다.

이중 반복문을 이용해 승리, 무승부, 패배 횟수를 계산한다.

```python
for a in a_sum:
    for b in b_sum:
        if a > b:
            win += 1
        if a = b:
            draw += 1
        if a < b:
            draw += 1

```
 => 그런데 이렇게하면 시간복잡도가 높아지므로( O (n^2) > 이분탐색을 활용한다..) 


### 5. 가장 승리 횟수가 높은 조합 선택하기

각 주사위 조합과 승리 횟수를 함께 저장한다.

```python
percent.append((choice, win))
```

이후 `max()`와 `lambda`를 이용해 승리 횟수가 가장 높은 조합을 찾으려고 한다.

```python
answer = max(percent(key=lambda percent: win))
```
