# 주사위 고르기 (완전탐색 + 이분탐색)

## 문제

A와 B가 n개의 주사위를 가지고 승부를 한다.

- 각 주사위에는 6개의 면이 있으며, 각 면이 나올 확률은 동일하다.
- 주사위에는 1부터 n까지 번호가 부여되어 있다.
- A가 먼저 n/2개의 주사위를 선택한다.
- B는 나머지 n/2개의 주사위를 가져간다.
- 각자 선택한 주사위를 모두 굴린 뒤, 나온 숫자의 합으로 승패를 결정한다.

### 승패 조건

- A의 합 > B의 합 → A 승리
- A의 합 = B의 합 → 무승부
- A의 합 < B의 합 → A 패배

### 목표

A가 승리할 확률이 가장 높아지도록 주사위 n/2개를 선택한다.

선택한 주사위 번호를 **오름차순으로 정렬한 배열**로 반환한다.

승리 확률이 가장 높은 주사위 조합은 유일하다.

### 입출력 예시

n = 4

| 주사위 | 구성 |
|---|---|
| #1 | [1, 2, 3, 4, 5, 6] |
| #2 | [3, 3, 3, 3, 4, 4] |
| #3 | [1, 3, 3, 4, 4, 4] |
| #4 | [1, 1, 4, 4, 5, 5] |

A가 선택한 주사위 조합에 따른 결과는 다음과 같다.

| A의 주사위 | 승 | 무 | 패 |
|---|---:|---:|---:|
| #1, #2 | 596 | 196 | 504 |
| #1, #3 | 560 | 176 | 560 |
| #1, #4 | 616 | 184 | 496 |
| #2, #3 | 496 | 184 | 616 |
| #2, #4 | 560 | 176 | 560 |
| #3, #4 | 504 | 196 | 596 |

따라서 정답은 **[1, 4]** 이다.

## 접근 방법

### 1. A가 선택할 수 있는 주사위 조합 구하기

A는 전체 n개의 주사위 중 n/2개를 선택한다.

따라서 `itertools.combinations`를 이용해 가능한 조합을 구한다.

```python
from itertools import combinations

n = len(dice)

choices = list(combinations(range(n), n//2))
```

예를 들어 n=4라면:

```python
choices = [
    (0, 1), (0, 2), (0, 3),
    (1, 2), (1, 3), (2, 3)
]
```

여기서 `choices`는 모든 선택 조합이고, `choice`는 그중 하나의 조합이다.

```python
for choice in choices:
    dice_a = [dice[i] for i in choice]
```

`choice`에는 주사위의 인덱스만 들어 있으므로, 실제 주사위의 눈을 가져오기 위해 `dice_a`를 만든다.

### 2. A의 선택에 따라 B의 주사위 결정하기

A가 주사위를 선택하면 B는 나머지 주사위를 가져간다.

```python
b_choice = [i for i in range(n) if i not in choice]
dice_b = [dice[i] for i in b_choice]
```

전체 주사위 인덱스 중 A가 선택하지 않은 인덱스를 구하는 방식이다.

**주의:** 리스트끼리는 `choices - choice`처럼 뺄셈할 수 없다.

### 3. 각 주사위를 굴렸을 때 가능한 합 구하기

A가 선택한 주사위를 모두 굴렸을 때 나올 수 있는 경우의 수는 다음과 같다.

`6 ** (n//2)`

B도 마찬가지다.

처음에는 주사위마다 중첩 for문을 작성하려고 했다.

```python
for first in dice_a[0]:
    for second in dice_a[1]:
        A_sum.append(first + second)
```

하지만 주사위가 3개, 4개로 늘어나면 for문도 계속 늘어나야 한다.

따라서 `itertools.product`를 이용한다.

```python
from itertools import product

A_sum = [sum(num) for num in product(*dice_a)]
B_sum = [sum(num) for num in product(*dice_b)]
```

`product(*dice_a)`는 선택한 각 주사위에서 눈을 하나씩 뽑는 모든 경우의 수를 생성한다.

`sum(num)`은 각 경우의 눈을 더한 값이다.

여기서 `*dice_a`의 `*`는 이차원 배열에 들어 있는 각 주사위를 개별 인자로 풀어주는 역할이다.

### 4. A와 B의 합을 비교하여 승리 횟수 계산하기

A와 B가 만들 수 있는 합을 각각 구했으므로, 두 배열의 모든 원소를 비교한다.

처음에는 이중 반복문을 생각했다.

```python
win = 0

for a in A_sum:
    for b in B_sum:
        if a > b:
            win += 1
```

하지만 A와 B의 경우의 수가 각각 `6 ** (n//2)`개이므로 모든 합을 직접 비교하면 연산량이 매우 커진다.

따라서 **정렬 + 이분탐색**으로 최적화한다.

```python
from bisect import bisect_left

B_sum.sort()

win = 0

for a in A_sum:
    win += bisect_left(B_sum, a)
```

`bisect_left(B_sum, a)`는 정렬된 B_sum에서 `a`를 삽입할 수 있는 가장 왼쪽 인덱스를 반환한다.

이 인덱스는 곧 **a보다 작은 B의 합계 개수**와 같다.

예를 들어:

```python
B_sum = [2, 3, 3, 5, 7]

bisect_left(B_sum, 5)  # 3
```

A의 합이 5라면 B의 합이 2, 3, 3인 경우에 승리하므로 3번 이긴다.

중복된 값도 각각 다른 주사위 결과이므로 모두 세어야 한다.

또한 A와 B의 전체 경우의 수는 모든 선택 조합에서 동일하므로 승리 확률 대신 **승리 횟수만 비교**해도 된다.

### 5. 가장 승리 횟수가 높은 조합 선택하기

각 주사위 조합과 승리 횟수를 함께 저장한다.

```python
percent.append((choice, win))
```

이후 `max()`와 `lambda`를 이용해 승리 횟수가 가장 높은 조합을 구할 수 있다.

```python
best_choice, max_win = max(percent, key=lambda x: x[1])
```

`x[0]`은 주사위 조합이고, `x[1]`은 승리 횟수다.

마지막으로 주사위 인덱스를 문제에서 요구하는 1부터 시작하는 번호로 변환한다.

```python
answer = [i + 1 for i in best_choice]
```

이 코드는 최초 사고 과정을 보존한 것으로, 문법 오류와 미완성 로직이 있어 실행되지 않는다.

주요 개선 사항:

- `combitations` → `combinations`
- `n/2` → `n//2`
- `choices - choice` → 리스트 컴프리헨션
- `dice(choice[0])` → `dice[choice[0]]`
- 주사위 개수에 따라 달라지는 중첩 for문 → `product()`
- A_sum과 B_sum의 전체 비교 → `bisect_left()`
- `win`은 각 조합마다 초기화해야 함
- `max()`의 `key` 사용법 수정

## Sol 2. 최종 풀이

```python
from itertools import combinations, product
from bisect import bisect_left


def solution(dice):
    answer = []
    percent = []

    n = len(dice)

    choices = list(combinations(range(n), n//2))

    for choice in choices:
        dice_a = [dice[i] for i in choice]

        b_choice = [i for i in range(n) if i not in choice]
        dice_b = [dice[i] for i in b_choice]

        A_sum = [sum(num) for num in product(*dice_a)]
        B_sum = [sum(num) for num in product(*dice_b)]

        B_sum.sort()

        win = 0

        for a in A_sum:
            win += bisect_left(B_sum, a)

        percent.append((choice, win))

    best_choice, max_win = max(percent, key=lambda x: x[1])

    answer = [i + 1 for i in best_choice]

    return answer
```

## 배운 점

### 1. A가 선택하지 않은 나머지 주사위 구하기

```python
b_choice = [i for i in range(n) if i not in choice]
```

전체 인덱스 중 A가 선택하지 않은 인덱스만 가져온다.

리스트와 튜플은 뺄셈 연산을 지원하지 않는다.

### 2. combinations()는 iterable을 인자로 받는다

```python
combinations(range(n), n//2)
```

`range(n)`은 리스트가 아니라 `range` 객체이지만, 반복 가능한 객체이므로 사용할 수 있다.

`combinations()`는 조합을 생성하는 iterator를 반환한다.

### 3. 주사위 번호와 실제 dice 배열 연결하기

```python
dice_a = [dice[i] for i in choice]
```

`choice`는 선택한 주사위의 인덱스이고, `dice_a`는 해당 주사위들의 실제 숫자가 들어 있는 이차원 배열이다.

주사위 번호를 1부터 만들었다면 `dice[i-1]`이 필요하지만, `range(n)`으로 만들었다면 `dice[i]`를 사용하면 된다.

### 4. itertools.product()

`product()`는 여러 iterable에서 각각 하나씩 선택하는 모든 경우의 수, 즉 데카르트 곱을 생성한다.

```python
from itertools import product

dice1 = [1, 2, 3]
dice2 = [4, 5]

for result in product(dice1, dice2):
    print(result)
```

결과:

```python
(1, 4)
(1, 5)
(2, 4)
(2, 5)
(3, 4)
(3, 5)
```

이차원 배열로 묶여 있다면 `*`로 풀어서 전달한다.

```python
dice_a = [dice1, dice2]

product(*dice_a)
```

### 5. product()와 sum()의 차이

`product()`는 가능한 조합을 만들고, `sum()`은 하나의 조합에 포함된 숫자를 더한다.

```python
A_sum = [sum(num) for num in product(*dice_a)]
```

`sum(product(*dice_a))`처럼 작성하면 튜플들을 직접 더하려 하므로 오류가 발생한다.

### 6. 이분탐색을 이용한 비교 최적화

이분탐색은 **정렬된 데이터에서 특정 값이나 경계를 빠르게 찾을 때** 사용한다.

```python
B_sum.sort()

for a in A_sum:
    win += bisect_left(B_sum, a)
```

B의 합을 정렬해 두면 A의 합보다 작은 B의 합이 몇 개인지 빠르게 구할 수 있다.

- 직접 비교: A의 합 하나당 O(m)
- 이분탐색: A의 합 하나당 O(log m)

여기서 m은 각 플레이어가 주사위를 굴렸을 때 나올 수 있는 경우의 수다.

### 7. max()와 lambda로 최댓값 찾기

```python
percent = [
    ((0, 1), 596),
    ((0, 2), 560),
    ((0, 3), 616)
]

best_choice, max_win = max(percent, key=lambda x: x[1])
```

`key=lambda x: x[1]`은 튜플의 두 번째 값인 승리 횟수를 기준으로 최댓값을 찾는다는 의미다.

결과:

```python
best_choice = (0, 3)
max_win = 616
```

## 엣지케이스

| 상황 | 확인할 점 |
|---|---|
| n=2인 경우 | A와 B가 주사위를 1개씩 선택 |
| 동일한 숫자가 반복되는 주사위 | 같은 합도 서로 다른 경우의 수로 계산 |
| 무승부가 많은 경우 | `bisect_left()`로 같은 합은 승리에서 제외 |
| 주사위마다 눈의 값이 크게 다른 경우 | 모든 가능한 합을 정확히 계산 |
| n이 큰 경우 | 이중 for문 대신 이분탐색 사용 |

## 시간복잡도

n: 전체 주사위 개수

m = 6 ** (n//2): 한 사람이 주사위를 굴렸을 때 가능한 결과 개수

C = n개 중 n/2개를 선택하는 조합의 개수



### . A_sum, B_sum 생성

각 조합에서 A와 B가 만들 수 있는 합은 각각 m개다.

각 합을 계산할 때 n/2개 숫자를 더하므로 O(nm)이 걸린다.

###  B_sum 정렬,이분탐색으로 승리 횟수 계산

`B_sum.sort()`

O(m log m)


### 최종 시간복잡도

모든 주사위 선택 조합 C개에 대해 위 과정을 반복한다.

**O(C × (nm + m log m))**

m = 6 ** (n//2)이므로 log m은 n에 비례한다.

따라서 전체 시간복잡도는 다음과 같이 정리할 수 있다.

**O(C × n × 6 ** (n//2))**

---

## 공간복잡도

- `choices`: O(C × n) — 모든 주사위 선택 조합 저장
- `A_sum`: O(m)
- `B_sum`: O(m)
- `percent`: O(C × n) — 조합과 승리 횟수 저장
- `product()` 자체는 결과를 한꺼번에 리스트로 만들지 않고 순차적으로 생성

따라서 전체 보조 공간복잡도는 **O(Cn + m)** 이다.

여기서 C는 조합의 개수, m은 `6 ** (n//2)`이다.

## 최종 정리

처음에는 combinations로 주사위를 선택한 뒤 중첩 for문을 사용해 모든 합과 승패를 직접 비교하려고 했다.

이 과정에서 다음과 같이 개선했다.

1. `combinations()`로 A가 선택할 주사위 조합 생성
2. 리스트 컴프리헨션으로 B의 나머지 주사위 결정
3. `product()`로 각 주사위에서 하나씩 눈을 뽑는 모든 경우 생성
4. `sum()`으로 가능한 합계 계산
5. `bisect_left()`로 A가 이기는 경우의 수를 빠르게 계산
6. `max(key=lambda x: x[1])`로 승리 횟수가 가장 높은 조합 선택

**핵심: 모든 경우의 수를 생성해야 하더라도, 모든 경우를 서로 직접 비교할 필요는 없다. 정렬과 이분탐색을 활용하면 비교 연산을 크게 줄일 수 있다.**
