
# 큰 수 만들기 (Greedy)

## 문제

어떤 숫자에서 k개의 수를 제거했을 때 얻을 수 있는 가장 큰 숫자를 구하려고 한다.

예를 들어 숫자 `1924`에서 수 두 개를 제거하면 다음과 같은 숫자를 만들 수 있다.

`[19, 12, 14, 92, 94, 24]`

이 중 가장 큰 숫자는 `94`이다.

문자열 형식으로 숫자 `number`와 제거할 수의 개수 `k`가 주어진다.

`number`에서 k개의 수를 제거했을 때 만들 수 있는 가장 큰 숫자를 **문자열 형태로 반환**한다.

---

## 문제 접근

### Sol 1. 가장 작은 숫자를 제거하는 방식

처음에는 숫자를 한 자리씩 분리한 뒤, 가장 작은 숫자부터 k개 제거하는 방식으로 접근했다.

```python
def solution(number, k):
    answer = ''
    numberlist = list(map(int, number))

    # 1, 9, 2, 4

    for i in range(k):  # k만큼 뺄 거니까
        min_number = min(numberlist)
        index = numberlist.index(min_number)  # 가장 작은 숫자 중 첫 번째 인덱스를 찾기

        numberlist.pop(index)  # 인덱스값을 빼다.

    answer = ''.join(map(str, numberlist))

    return answer
```

#### 시간복잡도에 대한 고민

이렇게 값으로 찾아서 빼면 아마 연산할 때마다 시간복잡도가 O(n)만큼 걸릴 것이다.

삭제 연산을 좀 더 빠르게 하는 방법이 있을까?

새로운 배열을 만들기?

투포인터로 삭제하는 것처럼 구현할 수 있었던 이유는 정렬되어 있고 한 방향으로만 가기 때문인데, 이 문제는 그런 상황이 아니다.

배열을 하나 더 복제한 다음 거기에서 뭔가 연산한다고 해도 포인터를 사용하는 방식이 아니기 때문에 어차피 동일하게 O(n)만큼의 연산이 발생할 것 같다.

#### 실행 결과 및 문제점

**TC 3개 중 2개만 맞았다.**

알고 보니까 시간복잡도 이전에 논리가 틀렸다.

무조건 작은 숫자를 제거하는 것이 정답은 아니다.

TC3을 커버하지 못한다.

**첫 번째 자릿수가 중요하다는 컨셉을 가져가야 한다.**

그러려면 `min()`을 찾는 게 아니라, for문으로 첫 번째 자릿수부터 훑으면서 다음과 같이 판단해야 할 것 같다.

- 앞의 숫자가 뒷자리 숫자보다 작다면 삭제한다.
- 앞의 숫자가 더 크다면 유지하고 다음 숫자로 넘어간다.
- 이러한 과정을 k개를 제거할 때까지 반복한다.

`while iter < k`를 사용하면 될 것 같다.

### Sol 2. 연속된 자릿수를 비교하는 방식

첫 번째 자릿수부터 순서대로 확인하면서, 바로 뒤의 숫자보다 작으면 제거하는 방식으로 접근했다.

```python
def solution(number, k):
    answer = ''
    numberlist = list(map(int, number))

    # 1, 9, 2, 4

    iter = 0
    now = 0

    while iter < k:
        if numberlist[now] < numberlist[now + 1]:
            # 앞의 자릿수가 더 작으므로 빼도 되는 상황
            numberlist.pop(now)
            iter += 1

        else:
            now += 1
            # 만약 앞의 자릿수가 더 큰 상황이라면
            # 그다음 자릿수를 가리키도록 하자.

    answer = ''.join(map(str, numberlist))

    return answer
```

#### 고민한 부분

그런데 걸리는 점이 있다.

**정말 바로 뒤에 있는 숫자(`now + 1`)만 비교해도 모든 경우를 커버할 수 있을까?**

아니다.

간혹 앞의 숫자도 다시 확인해야 한다.

만약 앞에 있는 숫자가 더 작으면 앞의 숫자를 제거해야 하기 때문이다.

즉, 단순히 `now`를 증가시키는 방식만으로는 모든 상황을 처리하기 어렵다.

## 배운 점

### 1. `map()` 함수

처음에는 숫자의 각 자릿수를 분리하기 위해 다음과 같은 방식을 생각했다.

- 1000의 자리로 나누기
- 100의 자리로 나누기
- 10의 자리로 나누기

이런 식으로 한 자릿수씩 뽑아내려고 했다.

그런데 파이썬의 `map()` 함수를 사용하면 간단하게 처리할 수 있었다.

#### 기본 문법

```python
map(적용할_함수, 반복할_데이터)
```

`map()`은 반복 가능한 객체에 사용할 수 있다.

문자열, 리스트, 튜플 등이 가능하다.

반면 정수형(`int`)은 한 자리씩 순회할 수 없는 자료형이다.

#### 사용 예시

```python
map(int, number)
```

`number`의 요소들을 하나씩 꺼내서 `int()` 함수를 각각 적용하라는 의미다.

```python
map(int, number)    # O: int 함수를 전달
map(int(), number)  # X: int 함수를 실행한 결과를 전달
```

#### `list()`로 감싸는 이유

`map()`은 리스트가 아니라 `map` 객체를 반환한다.

따라서 리스트로 만들기 위해 `list()`로 감싼다.

```python
numberlist2 = list(map(int, number))
```

#### `list(number)`와의 차이

```python
number = "1924"

a = list(number)
b = list(map(int, number))

print(a)  # ['1', '9', '2', '4']
print(b)  # [1, 9, 2, 4]
```

- `list(number)`는 문자열 원소를 가진 리스트를 만든다.
- `list(map(int, number))`는 정수 원소를 가진 리스트를 만든다.

---

### 2. `join()` 함수로 문자열 합치기

`join()` 함수는 리스트뿐 아니라 순서대로 값을 하나씩 꺼낼 수 있는 반복 가능한 객체(Iterable)도 사용할 수 있다.

숫자 리스트를 하나의 문자열로 합칠 때 다음과 같이 작성할 수 있다.

```python
answer = ''.join(map(str, numberlist))
```

정수로 변환하려면 다음과 같이 작성할 수도 있다.

```python
answer = int(''.join(map(str, numberlist)))
```

다만 이 문제에서는 문자열을 반환해야 하므로 `int()`로 변환하지 않는다.

### 3. `itertools`의 조합과 순열

문제풀이에 직접 사용하지는 않았지만, 조합과 순열을 구하는 `itertools` 관련 문법을 배웠다.

```python
import itertools
```

관련 함수:

```python
itertools.combinations()
itertools.permutations()
```

조합과 순열을 이용하면 가능한 경우를 만들어 볼 수 있다.

다만 경우의 수가 매우 많아질 수 있으므로 시간복잡도를 고려해야 한다.

처음에는 이러한 연산이 `n!` 수준까지 증가할 수 있다는 점 때문에 실제 코딩테스트에서 얼마나 활용할 수 있을지 고민했다.
