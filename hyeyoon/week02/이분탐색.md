# 이분 탐색 (Binary Search)

## 1. 개념

주사위 고르기 문제를 풀다가 이분 탐색 개념이 필요했다.

이분 탐색(이진 탐색)은 **정렬된 데이터에서 탐색 범위를 절반씩 줄여 원하는 값을 찾는 알고리즘**이다.

- 일반적인 선형 탐색(Full Scan): O(n)
- 이분 탐색: O(log n)
- 정렬(`sort()`): O(n log n)

단, 이분 탐색을 사용하려면 데이터가 정렬되어 있어야 한다.

이분 탐색은 크게 두 가지 유형으로 나눠서 공부할 수 있다.

## 2. 유형 ① 정렬된 배열에서 특정 값 찾기

정렬된 배열을 반씩 나누면서 원하는 값을 찾는 방식이다.

**키워드:** 특정 값 찾기, 존재 여부, 위치 찾기

### 기본 코드

```python
def binary_search(arr, target):
    left = 0
    right = len(arr) - 1

    while left <= right:
        mid = (left + right) // 2

        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1  # 찾지 못한 경우
```

- `left`: 탐색 범위의 시작
- `right`: 탐색 범위의 끝
- `mid`: 탐색 범위의 중간
- `arr[mid] < target`: 오른쪽 절반 탐색
- `arr[mid] > target`: 왼쪽 절반 탐색

시간복잡도: O(log n)

## 3. 유형 ② 정답을 이분 탐색하기 (매개변수 탐색)

**대표 문제: 프로그래머스 입국심사 Lv3**

특정 원소를 찾는 것이 아니라, **정답이 될 수 있는 값을 하나씩 가정하고 조건을 만족하는지 확인하는 방식**이다.

**키워드:** 최솟값, 최댓값, 가능한 최소 시간, 최대 길이

예를 들어 입국심사 문제에서는 특정 시간 `mid`를 가정하고, 그 시간 안에 모든 사람이 심사를 받을 수 있는지 확인한다.

가능하다면 시간을 더 줄여 보고, 불가능하다면 시간을 늘려 본다.

### 기본 코드 (최솟값 찾기)

```python
left = 1
right = 최대_가능한_값
answer = right

while left <= right:
    mid = (left + right) // 2

    if 조건을_만족(mid):
        answer = mid
        right = mid - 1  # 더 작은 정답 탐색
    else:
        left = mid + 1   # 더 큰 값 탐색
```

핵심은 **정답 후보의 범위를 절반씩 줄이는 것**이다.

단, 이 방법은 정답 후보에 대한 조건의 참/거짓이 한 방향으로 바뀌는 경우에 사용할 수 있다.

## 4. bisect 라이브러리

파이썬의 `bisect`는 정렬된 배열에서 이분 탐색으로 **값이 삽입될 위치**를 찾아주는 라이브러리다.

```python
from bisect import bisect_left, bisect_right
```

### bisect_left()

```python
arr = [1, 2, 2, 2, 4, 5]

print(bisect_left(arr, 2))  # 1
```

`2`를 삽입할 수 있는 가장 왼쪽 위치를 반환한다.

### bisect_right()

```python
print(bisect_right(arr, 2))  # 4
```

`2`를 삽입할 수 있는 가장 오른쪽 위치를 반환한다.

### 응용: 특정 숫자의 개수 구하기

```python
count = bisect_right(arr, 2) - bisect_left(arr, 2)

print(count)  # 3
```

### 주사위 고르기 문제에서의 활용

A의 점수보다 **작은 B의 점수가 몇 개 있는지** 구할 때 사용한다.

```python
B_sum.sort()

win = 0

for a in A_sum:
    win += bisect_left(B_sum, a)
```

`bisect_left(B_sum, a)`는 정렬된 `B_sum`에서 `a`보다 작은 원소의 개수를 반환한다.

따라서 모든 원소를 이중 for문으로 비교하지 않아도 승리 횟수를 구할 수 있다.

- 이중 for문: O(A × B)
- B 정렬 후 이분 탐색: O(B log B + A log B)

※ 여기서 A, B는 각각 `A_sum`, `B_sum`의 원소 개수다.

## 5. 정리

| 구분 | 일반 이분 탐색 | 매개변수 탐색 |
|---|---|---|
| 탐색 대상 | 정렬된 배열의 원소 | 정답이 될 수 있는 값 |
| 목적 | 특정 값의 위치나 존재 여부 확인 | 조건을 만족하는 최솟값/최댓값 |
| 대표 문제 | 주사위 고르기 (`bisect` 활용) | 입국심사 Lv3 |
| 핵심 | 중간 원소와 target 비교 | mid가 조건을 만족하는지 확인 |

**기억할 점**

- 이분 탐색은 탐색 범위를 절반씩 줄이므로 O(log n)이다.
- `mid = (left + right) // 2`로 계산한다.
- `bisect_left()`는 같은 값이 있을 때 가장 왼쪽 삽입 위치를 반환한다.
- 매개변수 탐색은 정답 후보에 대해 가능/불가능을 판별할 수 있어야 한다.
