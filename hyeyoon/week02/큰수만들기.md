문제 설명
어떤 숫자에서 k개의 수를 제거했을 때 얻을 수 있는 가장 큰 숫자를 구하려 합니다.

예를 들어, 숫자 1924에서 수 두 개를 제거하면 [19, 12, 14, 92, 94, 24] 를 만들 수 있습니다. 이 중 가장 큰 숫자는 94 입니다.

문자열 형식으로 숫자 number와 제거할 수의 개수 k가 solution 함수의 매개변수로 주어집니다. number에서 k 개의 수를 제거했을 때 만들 수 있는 수 중 가장 큰 숫자를 문자열 형태로 return 하도록 solution 함수를 완성하세요.

sol 1.  접근과 풀이 




def solution(number, k):
    answer = ''
    numberlist = list(map(int,number))

    #1,9,2,4 

    for i in range(k): #k만큼 뺄거니까 
        min_number=min(numberlist)
        index=numberlist.index(min_number) #가장 작은 숫자중에 첫번째 인덱스를 찾기 
        
        numberlist.pop(index) #인덱스값을 뺴다. 

 #근데 이렇게 값으로 찾아서 뺴면아마 연산할떄마다 시간복잡도가 O(n) 만큼 걸릴거임 -> 삭제 연산을 좀 더 빠르게 하는 방법이 있을까? 새로운 배열을 만들기? 왜냐면 투포언터로 삭제하는 것처럼 구현할수잇었던 이유는 정렬되었구 한방향으로만 가기 때문인데 , 얘는 그런까라가 아님.. 배열을 하나 더 복제한다음 거기에ㅓㅅ 뭔가연산을 한다고해도 그건 포인터가 아니기 떄문에 어차피 동일하게 O(n)만큼의 연산을 만들어내게 됨.. 
        
    answer= ''.join(map(str,numberlist))
    
    return answer

def solution(number, k):
    answer = ''
    numberlist = list(map(int,number))

    #1,9,2,4 

    iter=0 
    now=0
    
    while iter<k:
        if numberlist[now]<numberlist[now+1]: #앞의 자릿수가 더 작으므로 뺴도되는 상황 . 
            numberlist.pop(now)
            iter+=1
        

        else  
            now+=1 #만약 앞의 자릿수가 더 큰 상황이라면 그 다음자릿수를 가리키도록하자. 

        
        
    
    answer= ''.join(map(str,numberlist))
    
    return answer
