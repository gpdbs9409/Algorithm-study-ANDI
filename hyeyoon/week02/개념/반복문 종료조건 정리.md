
## 반복문 종료 및 제어 문법

| 문법 | 의미 | 실행 결과 |
|---|---|---|
| `break` | 반복문 종료 | 반복문 밖으로 이동 |
| `continue` | 현재 반복 건너뛰기 | 다음 반복 시작 |
| `pass` | 아무것도 하지 않음 | 바로 다음 코드 실행 |
| `return` | 함수 종료 | 값 반환 후 함수 종료 |

### 1. break — 반복문 종료

```python
for i in range(5):
    if i == 2:
        break
    print(i)

# 출력: 0, 1
```

`break`는 **가장 가까운 반복문 하나만 종료**한다.

### 2. continue — 이번 반복만 건너뛰기

```python
for i in range(5):
    if i == 2:
        continue
    print(i)

# 출력: 0, 1, 3, 4
```

`continue`는 아래 코드를 건너뛰고 다음 반복으로 넘어간다.

### 3. pass — 아무것도 하지 않기

```python
for i in range(3):
    if i == 1:
        pass
    print(i)

# 출력: 0, 1, 2
```

`pass`는 흐름을 바꾸지 않는다. 주로 코드 작성 전 자리만 채울 때 사용한다. (todO로 추후 채울건데 그냥 if문만 떨렁써놓으면 에러나니까 안에 뭐라도 채우는거임 ) 

### 4. return — 함수 자체 종료

```python
def solution():
    for i in range(5):
        if i == 2:
            return i
    print("END")

print(solution())

# 출력: 2
```

`return`은 반복문뿐 아니라 **함수 전체를 종료**한다.

### 5. while — 조건이 거짓이면 종료

```python
i = 0

while i < 3:
    print(i)
    i += 1

# 출력: 0, 1, 2
```

`while`은 조건이 `False`가 되거나 `break`를 만나면 종료된다.

### ⭐ 핵심 암기

- **break:** 반복문 탈출
- **continue:** 이번 턴 스킵
- **pass:** 아무것도 안 함
- **return:** 함수 탈출
- **while:** 조건이 참인 동안 반복

참고로 `break`, `continue`는 `if` 안에 작성할 수 있지만, 반드시 반복문 내부에 있어야 해.
