#문제 당신은 표 편집 프로그램을 작성하고 있습니다.
표의 크기는 50 × 50으로 고정되어있고 초기에 모든 셀은 비어 있습니다.
각 셀은 문자열 값을 가질 수 있고, 다른 셀과 병합될 수 있습니다.

위에서 r번째, 왼쪽에서 c번째 위치를 (r, c)라고 표현할 때, 당신은 다음 명령어들에 대한 기능을 구현하려고 합니다.

"UPDATE r c value"
(r, c) 위치의 셀을 선택합니다.
선택한 셀의 값을 value로 바꿉니다.
"UPDATE value1 value2"
value1을 값으로 가지고 있는 모든 셀을 선택합니다.
선택한 셀의 값을 value2로 바꿉니다.
"MERGE r1 c1 r2 c2"
(r1, c1) 위치의 셀과 (r2, c2) 위치의 셀을 선택하여 병합합니다.
선택한 두 위치의 셀이 같은 셀일 경우 무시합니다.
선택한 두 셀은 서로 인접하지 않을 수도 있습니다. 이 경우 (r1, c1) 위치의 셀과 (r2, c2) 위치의 셀만 영향을 받으며, 그 사이에 위치한 셀들은 영향을 받지 않습니다.
두 셀 중 한 셀이 값을 가지고 있을 경우 병합된 셀은 그 값을 가지게 됩니다.
두 셀 모두 값을 가지고 있을 경우 병합된 셀은 (r1, c1) 위치의 셀 값을 가지게 됩니다.
이후 (r1, c1) 와 (r2, c2) 중 어느 위치를 선택하여도 병합된 셀로 접근합니다.
"UNMERGE r c"
(r, c) 위치의 셀을 선택하여 해당 셀의 모든 병합을 해제합니다.
선택한 셀이 포함하고 있던 모든 셀은 프로그램 실행 초기의 상태로 돌아갑니다.
병합을 해제하기 전 셀이 값을 가지고 있었을 경우 (r, c) 위치의 셀이 그 값을 가지게 됩니다.
"PRINT r c"
(r, c) 위치의 셀을 선택하여 셀의 값을 출력합니다.
선택한 셀이 비어있을 경우 "EMPTY"를 출력합니다.

## 접근방식 및 배운 점

1. 먼저 50×50 크기의 2차원 배열을 생성한다. 모든 셀의 초기값은 "EMPTY"로 설정한다.

2. commands의 각 문자열을 split()으로 분리한다. parts[0]으로 명령어 종류를 확인하고 분기 처리한다.

3. UPDATE r c value
   - 특정 위치의 값을 변경한다.
   - 단, 병합된 셀이라면 해당 그룹의 대표 셀 값을 변경해야 한다.

4. UPDATE value1 value2
   - 표 전체를 순회하면서 value1을 가진 셀을 찾아 value2로 변경한다.

5. MERGE r1 c1 r2 c2
   - 따라서 단순히 값을 복사하는 것이 아니라, 병합된 모든 셀이 하나의 값을 참조하도록 만들어야 한다.
   - 처음에는 C의 포인터처럼 같은 값을 참조하는 방식을 떠올렸다.
   - Python에서는 별도의 배열을 만들어 각 셀이 대표 셀을 가리키도록 구현할 수 있다고 생각했다.
   - 또는 딕셔너리를 이용해 `{(1, 1): {(1, 1), (1, 2), (1, 3)}}`처럼 그룹을 관리하는 방법도 고민했다.
   - 하지만 그룹끼리 다시 병합될 수 있기 때문에 각 셀이 속한 그룹을 관리하는 방법이 필요했다.
   - **Union-Find(서로소 집합) 자료구조를 활용한다.**
  
   - http://github.com/gpdbs9409/Algorithm-study-ANDI/blob/main/hyeyoon/unionFind%EA%B0%9C%EB%85%90%2C%EB%8C%80%ED%91%9C%EC%98%88%EC%A0%9C.md

6. Union-Find
   - Find: 특정 셀이 속한 그룹의 대표 셀을 찾는다.
   - Union: 두 셀이 속한 그룹을 하나로 합친다.
   - matrix: 각 대표 셀이 관리하는 값을 저장한다.
   - parent: 각 셀이 어느 대표 셀을 가리키는지 저장한다.
   - 병합되지 않은 셀은 자기 자신을 대표로 가진다.
   - 따라서 별도의 병합 여부 T/F 배열은 필요하지 않다.

7. UNMERGE
   - 아직 구현하지 않음.

8. PRINT
   - 아직 구현하지 않음.

def solution(commands):

    # 50×50 배열 생성 (좌표가 1부터 시작하므로 51×51 사용)
    matrix = [["EMPTY"] * 51 for _ in range(51)]

    # 각 셀이 가리키는 대표 셀을 저장
    parent = [
        [(r, c) for c in range(51)]
        for r in range(51)
    ]

    answer = []
    


    #  유니언파인드 구현 1 - 특정 셀이 속한 그룹의 대표 셀 찾기 
    def find(r, c):

        if parent[r][c] == (r, c):
            return (r, c)

        parent[r][c] = find(parent[r][c])

        return parent[r][c]


    #  유니언파인드 구현 2 - a와 b
    
    def union(rx,ry,cx,cy): #3번 명령어인 Merge에서 사용하게 될것임. 
        
        root_r=find(rx,ry)
        root_c=find(cx,cy)
        
        if root_r!=root_c:
            parent[root_c]=root_r
        
        #두 셀중 하나의 셀이 값을 가지고 있을경우 병합된 셀은 그 값을 가지고, 만약 둘다 가지고 있다면 첫번째 셀의 값으로 통합시킴 .
        if matrix[rx][ry] or matrix[cx][cy]: 
            
            if matrix[cx][cy] and not matrix[rx][ry]:
                matrix[cx][cy]=matrix[rx][ry]

            else matrix[cx][cy] and matrix[rx][ry]: #둘다 값이 있는 경우에는 r의 값으로 덮어쓰고 
                matrix[cx][cy]=matrix[rx][ry]
            
            
        
        
            
    for command in commands: #실제 명령어를 실행하는 구간. 
        parts = command.split() #parts로 명령어를 쪼개서 어떤 명령어 타입인지 알아볼수있게 만듦 

        # 첫 번째 조건: UPDATE r c value
        if parts[0] == "UPDATE" and len(parts) == 4:

            r = int(parts[1])
            c = int(parts[2])
            value = parts[3]

            # 병합된 셀이라면 대표 셀의 값을 변경
            pr, pc = find(r, c)
            matrix[pr][pc] = value

        # 두 번째 조건: UPDATE value1 value2
        elif parts[0] == "UPDATE" and len(parts) == 3:

            value1 = parts[1]
            value2 = parts[2]

            # 표 전체를 순회하며 값 변경
            for r in range(1, 51):

                    pr, pc = find(r, c)

                    if matrix[pr][pc] == value1:
                        matrix[pr][pc] = value2

        # 세 번째 조건: MERGE r1 c1 r2 c2
        elif parts[0] == "MERGE":
