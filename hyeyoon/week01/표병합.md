# 문제

50×50 크기의 표가 주어진다. 각 셀은 `(r, c)` 좌표로 구분하며, 초기에는 모든 셀이 비어 있다.

다음 다섯 가지 명령어를 구현해야 한다.

### 1. UPDATE r c value

- `(r, c)` 위치의 셀 값을 `value`로 변경한다.
- 해당 셀이 다른 셀과 병합되어 있다면, 병합된 그룹 전체의 값이 변경된다.

### 2. UPDATE value1 value2

- 표에서 `value1`을 가진 모든 셀의 값을 `value2`로 변경한다.

### 3. MERGE r1 c1 r2 c2

- 두 셀이 속한 그룹을 하나로 병합한다.
- 이미 같은 그룹에 속해 있다면 아무 작업도 하지 않는다.
- 두 그룹 중 하나만 값을 가지고 있다면 해당 값을 유지한다.
- 두 그룹 모두 값을 가지고 있다면 **첫 번째 셀이 속한 그룹의 값**을 유지한다.

### 4. UNMERGE r c

- `(r, c)`가 속한 그룹의 모든 병합을 해제한다.
- 그룹에 속했던 셀들은 각각 독립적인 셀로 돌아간다.
- **기존 그룹의 값은 명령어에서 지정한 `(r, c)` 셀에만 남는다.**
- 나머지 셀들은 모두 `EMPTY`가 된다.

### 5. PRINT r c

- `(r, c)` 셀의 값을 조회한다.
- 비어 있다면 `"EMPTY"`를 반환한다.

`PRINT` 명령어의 결과들을 순서대로 리스트에 담아 반환해야 한다.

---

# 접근방법

## 1. 왜 Union-Find를 사용하는가?

이 문제에서 중요한 것은 개별 셀의 값뿐만 아니라 **어떤 셀들이 하나의 그룹으로 병합되어 있는지** 관리하는 것이다.

예를 들어 다음과 같이 셀들이 병합되어 있다고 가정하자.

```text
(1,1) ← (1,2) ← (1,3)
```

세 셀은 서로 다른 좌표를 가지고 있지만, 논리적으로는 하나의 그룹이다.

따라서 `(1,3)`에 `UPDATE` 명령어가 들어와도 실제로는 그룹 전체의 값을 변경해야 한다.

이를 위해 Union-Find를 사용한다.

- `find()`: 특정 셀이 속한 그룹의 대표 셀을 찾는다.
- `union()`: 서로 다른 두 그룹을 하나로 병합한다.
- `parent`: 각 셀이 가리키는 부모 셀의 좌표를 저장한다.

핵심은 **그룹의 대표 셀에만 값을 저장하는 것**이다.

---

## 2. 자료구조 설계

### matrix

```python
matrix = [["EMPTY"] * 51 for _ in range(51)]
```

- 각 그룹의 값을 저장하는 2차원 배열이다.
- 병합된 그룹의 값은 대표 셀에 저장한다.
- 좌표가 1부터 50까지이므로 편의를 위해 51×51 배열을 사용한다.

### parent

```python
parent = [
    [(r, c) for c in range(51)]
    for r in range(51)
]
```

- 각 셀의 부모 좌표를 저장한다.
- 초기에는 모든 셀이 자기 자신을 부모로 가진다.
- `parent[r][c] == (r, c)`라면 해당 셀이 현재 그룹의 대표 셀이다.

예를 들어 다음과 같이 저장될 수 있다.

```python
parent[3][3] = (2, 2)
parent[2][2] = (1, 1)
parent[1][1] = (1, 1)
```

이는 다음 관계를 의미한다.

```text
(3,3) → (2,2) → (1,1)
                    ↑
                  대표 셀
```

---

## 3. find(): 그룹의 대표 셀 찾기

```python
def find(r, c):

    if parent[r][c] == (r, c):
        return (r, c)

    parent[r][c] = find(*parent[r][c])

    return parent[r][c]
```

### 동작 원리

1. 현재 셀의 부모가 자기 자신이라면 대표 셀이므로 반환한다.
2. 아니라면 부모 셀을 대상으로 `find()`를 재귀호출한다.
3. 재귀호출의 반환값으로 최종 대표 셀을 알아낸다.
4. 현재 셀의 부모를 최종 대표 셀로 변경한다.

4번 과정이 **경로 압축(Path Compression)** 이다.

경로 압축을 통해 이후의 대표 셀 탐색을 빠르게 할 수 있다.

---

## 4. union(): 두 그룹 병합

```python
root_r = find(rx, ry)
root_c = find(cx, cy)
```

먼저 두 셀이 속한 그룹의 대표를 찾는다.

두 대표가 같다면 이미 같은 그룹이므로 병합하지 않는다.

대표가 다르다면 두 번째 그룹의 대표가 첫 번째 그룹의 대표를 가리키도록 변경한다.

```python
parent[r2][c2] = root_r
```

### 병합할 때 값 처리

문제에서는 첫 번째 셀이 속한 그룹의 값을 우선한다.

따라서 다음 두 경우만 확인하면 된다.

```python
if matrix[r1][c1] != "EMPTY":
    value = matrix[r1][c1]
else:
    value = matrix[r2][c2]
```

| 첫 번째 그룹 | 두 번째 그룹 | 병합 결과 |
|---|---|---|
| A | B | A |
| A | EMPTY | A |
| EMPTY | B | B |
| EMPTY | EMPTY | EMPTY |

이후 새 대표 셀에 병합된 값을 저장하고, 기존 대표 셀의 값은 초기화한다.

```python
matrix[r1][c1] = value
matrix[r2][c2] = "EMPTY"
```

**주의:** 병합 명령어에 전달된 좌표가 반드시 대표 셀인 것은 아니다. 따라서 `matrix[rx][ry]`가 아니라 `find()`로 구한 대표 셀의 값을 확인해야 한다.

---

## 5. UPDATE 구현

### UPDATE r c value

특정 셀을 업데이트할 때는 먼저 해당 셀이 속한 그룹의 대표를 찾는다.

```python
pr, pc = find(r, c)
matrix[pr][pc] = value
```

대표 셀에만 값을 저장하기 때문에 그룹에 속한 모든 셀의 값을 개별적으로 수정할 필요가 없다.

### UPDATE value1 value2

표 전체를 순회하면서 각 셀의 대표를 찾고, 대표 셀의 값이 `value1`이면 `value2`로 변경한다.

```python
for r in range(1, 51):
    for c in range(1, 51):

        pr, pc = find(r, c)

        if matrix[pr][pc] == value1:
            matrix[pr][pc] = value2
```

동일한 그룹의 대표 셀을 여러 번 확인할 수 있지만, 값을 `value1`에서 `value2`로 변경하는 동작이므로 문제없이 처리된다.

---

## 6. UNMERGE 구현

이 문제에서 가장 까다로운 부분이다.

`MERGE`는 두 그룹의 대표를 연결하면 되지만, `UNMERGE`는 **특정 그룹에 속한 모든 셀을 찾아서 각각 독립적인 셀로 되돌려야 한다.**

### ① 그룹의 대표와 기존 값 저장

```python
pr, pc = find(r, c)
will_rc = matrix[pr][pc]
```

병합을 해제하기 전에 기존 값을 저장해야 한다.

`UNMERGE`에서 지정된 셀이 대표 셀이 아닐 수도 있으므로 반드시 대표 셀의 값을 가져와야 한다.

### ② 같은 그룹에 속한 모든 셀 찾기

```python
group = []

for i in range(1, 51):
    for j in range(1, 51):

        if find(i, j) == (pr, pc):
            group.append((i, j))
```

Union-Find의 `parent` 배열은 **자식 → 부모** 관계를 저장한다.

반대로 특정 부모에 속한 모든 자식의 목록을 직접 가지고 있지는 않다.

따라서 전체 셀을 순회하면서 같은 대표를 가진 셀들을 찾아야 한다.

### ③ 그룹의 모든 셀 초기화

```python
for i, j in group:
    parent[i][j] = (i, j)
    matrix[i][j] = "EMPTY"
```

모든 셀을 독립적인 상태로 되돌린다.

### ④ 지정된 셀에만 기존 값 복원

```python
matrix[r][c] = will_rc
```

### 왜 그룹을 먼저 수집해야 할까?

처음에는 전체 셀을 순회하면서 같은 그룹을 찾는 즉시 `parent`를 초기화하려고 했다.

하지만 다음 관계를 생각해 보자.

```text
C → B → A
```

A가 대표 셀인데 B를 먼저 독립시켜 버리면 다음과 같이 된다.

```text
C → B     A
```

이후 `find(C)`의 결과가 달라질 수 있다.

즉, **탐색 도중 부모 관계를 수정하면 아직 탐색하지 않은 셀의 그룹 판별 결과가 바뀔 수 있다.**

따라서 다음 순서로 처리해야 한다.

```text
기존 그룹 탐색
      ↓
그룹 구성원 전체 수집
      ↓
모든 셀의 부모 관계 초기화
      ↓
지정된 셀에 기존 값 복원
```

## 7. PRINT 구현

```python
r = int(parts[1])
c = int(parts[2])

pr, pc = find(r, c)

answer.append(matrix[pr][pc])
```

병합된 셀은 자신의 좌표에 값이 저장되어 있지 않을 수 있다.

따라서 대표 셀을 찾은 뒤 대표 셀의 값을 조회해야 한다.

또한 문제에서는 출력 결과를 리스트로 반환해야 하므로 `print()`가 아니라 `answer.append()`를 사용한다.

---

# sol

```python
def solution(commands):

    # 50×50 배열 생성 (좌표가 1부터 시작하므로 51×51 사용)
    matrix = [["EMPTY"] * 51 for _ in range(51)]

    # 각 셀이 가리키는 대표 셀을 저장
    parent = [
        [(r, c) for c in range(51)]
        for r in range(51)
    ]

    answer = []

    # 유니언파인드 구현 1 - 특정 셀이 속한 그룹의 대표 셀 찾기
    def find(r, c):

        if parent[r][c] == (r, c):
            return (r, c)

        # 경로 압축
        parent[r][c] = find(*parent[r][c])

        return parent[r][c]

    # 유니언파인드 구현 2 - 두 셀이 속한 그룹 병합
    def union(rx, ry, cx, cy):

        root_r = find(rx, ry)
        root_c = find(cx, cy)

        # 이미 같은 그룹이면 병합하지 않음
        if root_r == root_c:
            return

        # 대표 셀의 좌표
        r1, c1 = root_r
        r2, c2 = root_c

        # 첫 번째 셀의 값이 우선
        # 첫 번째 셀이 비어 있으면 두 번째 셀의 값 사용
        if matrix[r1][c1] != "EMPTY":
            value = matrix[r1][c1]
        else:
            value = matrix[r2][c2]

        # 두 그룹 병합
        parent[r2][c2] = root_r

        # 병합된 그룹의 대표 셀에 값 저장
        matrix[r1][c1] = value
        matrix[r2][c2] = "EMPTY"

    # 실제 명령어 실행
    for command in commands:

        parts = command.split()

        # 1. UPDATE r c value
        if parts[0] == "UPDATE" and len(parts) == 4:

            r = int(parts[1])
            c = int(parts[2])
            value = parts[3]

            # 병합된 셀이라면 대표 셀의 값을 변경
            pr, pc = find(r, c)
            matrix[pr][pc] = value

        # 2. UPDATE value1 value2
        elif parts[0] == "UPDATE" and len(parts) == 3:

            value1 = parts[1]
            value2 = parts[2]

            # 표 전체를 순회하며 값 변경
            for r in range(1, 51):
                for c in range(1, 51):

                    pr, pc = find(r, c)

                    if matrix[pr][pc] == value1:
                        matrix[pr][pc] = value2

        # 3. MERGE r1 c1 r2 c2
        elif parts[0] == "MERGE":

            r1 = int(parts[1])
            c1 = int(parts[2])
            r2 = int(parts[3])
            c2 = int(parts[4])

            union(r1, c1, r2, c2)

        # 4. UNMERGE r c
        elif parts[0] == "UNMERGE":

            r = int(parts[1])
            c = int(parts[2])

            # 현재 그룹의 대표 셀 찾기
            pr, pc = find(r, c)

            # 병합 해제 전에 기존 값 저장
            will_rc = matrix[pr][pc]

            # 같은 그룹에 속한 모든 셀 수집
            group = []

            for i in range(1, 51):
                for j in range(1, 51):

                    if find(i, j) == (pr, pc):
                        group.append((i, j))

            # 그룹에 속한 모든 셀의 병합 해제
            for i, j in group:
                parent[i][j] = (i, j)
                matrix[i][j] = "EMPTY"

            # 선택한 셀에만 기존 값 복원
            matrix[r][c] = will_rc

        # 5. PRINT r c
        elif parts[0] == "PRINT":

            r = int(parts[1])
            c = int(parts[2])

            pr, pc = find(r, c)

            answer.append(matrix[pr][pc])

    return answer
```

# 틀렸던 이유



##  UNMERGE에서 부모 관계를 바로 초기화하려고 함

처음에는 전체 셀을 순회하면서 같은 그룹의 셀을 발견하면 즉시 부모 관계를 초기화하려고 했다.

하지만 부모 관계를 변경하면 아직 탐색하지 않은 셀의 `find()` 결과까지 바뀔 수 있다.

따라서 다음과 같이 수정했다.

```python
group = []

for i in range(1, 51):
    for j in range(1, 51):
        if find(i, j) == (pr, pc):
            group.append((i, j))

for i, j in group:
    parent[i][j] = (i, j)
    matrix[i][j] = "EMPTY"


```

# 배운점

## 1. Union-Find는 그룹의 연결 관계를 관리하는 자료구조다

Union-Find는 서로소 집합(Disjoint Set)을 관리하기 위한 자료구조이다.

주요 연산은 다음 두 가지이다.

- `find(x)`: 원소 `x`가 속한 집합의 대표 원소를 찾는다.
- `union(a, b)`: 두 원소가 속한 집합을 하나로 합친다.

이번 문제에서는 원소가 숫자 하나가 아니라 `(r, c)` 형태의 2차원 좌표였다.

따라서 `parent`에도 부모의 좌표를 튜플로 저장했다.

```python
parent[r][c] = (pr, pc)
```

**핵심:** 각 셀의 좌표가 다르더라도 `find()` 결과가 같으면 같은 그룹에 속한다.

---

## 2. 재귀함수에서 return은 어디로 돌아가는가?

이번 문제에서 가장 헷갈렸던 부분은 다음 코드였다.

```python
parent[r][c] = find(*parent[r][c])
```

처음에는 루트에 도달해서 `return`을 실행하면 반환값이 어디로 전달되는지 이해하지 못했다.

특히 반환값이 직전 함수의 **인자로 전달되는 것인지** 헷갈렸다.

하지만 반환값은 인자로 전달되는 것이 아니다.

**함수가 호출되었던 자리의 실행 결과가 된다.**

예를 들어:

```python
def add(a, b):
    return a + b

result = add(3, 5)
```

`add(3, 5)`가 `8`을 반환하면 다음과 같이 생각할 수 있다.

```python
result = 8
```

재귀함수에서도 원리는 동일하다.

```python
parent[3] = find(2)
```

여기서 `find(2)`가 `0`을 반환하면:

```python
parent[3] = 0
```

이 되는 것이다.

즉, `return`은 **함수를 호출했던 위치로 값을 돌려준다.**

---

## 3. 재귀호출은 내려갈 때와 돌아올 때를 구분해야 한다

다음과 같은 부모 배열을 생각해 보자.

```python
parent = [0, 0, 1, 2]
```

부모 관계는 다음과 같다.

```text
3 → 2 → 1 → 0
            ↑
           루트
```

다음 함수를 실행한다.

```python
def find(x):

    if parent[x] == x:
        return x

    parent[x] = find(parent[x])

    return parent[x]
```

### ① 재귀호출: 루트를 찾으러 내려가는 과정

```text
find(3)
  │
  └── find(2)
        │
        └── find(1)
              │
              └── find(0)
                    │
                    └── return 0
```

각 함수는 내부에서 호출한 `find()`가 끝나기를 기다린다.

예를 들어 `find(3)`에서는:

```python
parent[3] = find(2)
```

오른쪽의 `find(2)`가 아직 반환되지 않았으므로 대입이 완료되지 않는다.

### ② 재귀 반환: 루트를 찾고 돌아오는 과정

```text
find(0) → return 0
                ↓
find(1) → parent[1] = 0
          return 0
                ↓
find(2) → parent[2] = 0
          return 0
                ↓
find(3) → parent[3] = 0
          return 0
```

최종적으로:

```python
parent = [0, 0, 0, 0]
```

이 된다.

**재귀호출은 안쪽 함수부터 실행이 끝나고, 반환값은 호출 순서의 반대로 전달된다.**

---

## 4. find()의 경로 압축(Path Compression)

```python
parent[x] = find(parent[x])
```

이 코드는 단순히 루트를 찾는 것 이상의 역할을 한다.

### 경로 압축 전

```text
3 → 2 → 1 → 0
```

### 경로 압축 후

```text
3 ──┐
2 ──┼──→ 0
1 ──┘
```

`find(3)`을 실행하면서 거쳐 간 원소들의 부모를 최종 루트인 `0`으로 변경한다.

이렇게 하면 이후 같은 그룹의 대표를 찾을 때 중간 노드를 여러 번 거칠 필요가 없다.
이 코드는 루트를 찾으면서 부모 배열까지 갱신한다.

**배운 점:** 재귀함수의 반환값을 이용하면 탐색 결과를 상위 호출에 전달하는 동시에 자료구조의 상태도 갱신할 수 있다.

---

## 5. 왜 find()에는 return이 두 번 있는가?

```python
def find(x):

    if parent[x] == x:
        return x

    parent[x] = find(parent[x])

    return parent[x]
```

### 첫 번째 return

```python
if parent[x] == x:
    return x
```

현재 원소가 루트라면 더 이상 탐색할 필요가 없으므로 루트를 반환한다.

재귀호출을 끝내는 **종료 조건(Base Case)** 이다.

### 두 번째 return

```python
return parent[x]
```

재귀호출을 통해 알아낸 최종 루트를 **현재 함수를 호출했던 위치에 반환한다.**

이 반환이 없으면 상위 함수는 필요한 루트 값을 전달받지 못한다.

따라서 재귀함수에서는 종료 조건뿐만 아니라 **재귀호출이 끝난 뒤 결과를 어떻게 반환할지도 중요하다.**

# 시간복잡도

commands를 n이라고 가정하고, 매트릭스 한변의 길이를 m으로 가정한다. 
O(n) 이고 명령어중에 가장 많이 시간복잡도가 드는 unmerge를 기준으로 보면(원하는 값을 찾기위해 50*50 matrix를 fullscan하므로) 
O(n m^2)  또한 find연산이 특정상황에서는 부모의 연결이 길어져서 O(m^2)만큼 증가할수도있으므로 

O(nm⁴)이다.

# 공간복잡도
일단 matrix가 m^2만큼필요하고, parents도 m^2만큼 필요하므로 2 O(m^2) => O(m^2) 
그리고 각 명령어에서 따로 group등의 배열이 할당되지만 M^2의 차원을 넘어가는 것은 없어보이므로 같은 차수에 포함하면된다. 

*반환값을 포함한다면 print가 command의 갯수인 n만큼 최대로 쌓일수있기 때문에.. O(m^2+n)
