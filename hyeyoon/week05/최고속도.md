
# 최고 속도

- 플랫폼: 프로그래머스
- 유형: 그래프, DFS, 백트래킹, 시뮬레이션
- 문제: https://school.programmers.co.kr/learn/courses/30/lessons/468376

## 접근방법

### 1. 도로를 그래프로 변환한다.

현재 도로는 그래프 형태가 아니라 두 지점의 좌표로 주어져 있다.

따라서 `road`를 순회하면서 각 도로를 구간으로 만들고, 도로끼리 교차하는 지점을 찾아야 한다.

- 가로 도로와 세로 도로가 교차하는지 확인한다.
- 도로가 겹치거나 만나는 지점을 찾는다.
- 도로의 양 끝점, 교차점, 도시, 카메라 위치를 노드로 만든다.
- 같은 도로에 존재하는 노드들을 순서대로 연결한다.

이렇게 하면 좌표로 표현된 도로를 그래프로 바꿀 수 있다.

### 2. DFS + 백트래킹으로 가능한 최고 속도를 구한다.

교차하는 지점을 그래프의 노드라고 생각하고 완전탐색으로 풀어보자.

출발 도시에서 다른 도시까지 이동하는 모든 경로를 탐색하면서, 각 경로의 최저 제한 속도를 저장한다.

**한 경로에서 가능한 최고 속도는 그 경로에서 만나는 제한 속도 중 최솟값이다.**

예를 들어 다음과 같은 경로가 있다고 하자.

- 경로 A: `100 → 60 → 90` → 최저 속도 `60`
- 경로 B: `80 → 80 → 70` → 최저 속도 `70`

따라서 가능한 최고 속도는 `max(60, 70) = 70`이다.

DFS로 탐색하면서 현재 경로의 최저 속도를 `min()`으로 갱신하고, 각 노드에 도착할 수 있는 최고 속도를 `max()` 개념으로 관리한다.

단, 모든 경로를 탐색하면 시간 초과가 발생할 수 있으므로 가지치기를 적용한다.

- 이전보다 높은 속도로 도착했다면 다시 탐색한다.
- 이전보다 낮거나 같은 속도로 도착했다면 탐색하지 않는다.

### 3. 모든 도시의 결과를 answer에 저장한다.

1번 도시에서 DFS를 한 번 실행하면 다른 도시들까지 도달 가능한 최고 속도를 구할 수 있다.

따라서 2번, 3번, 4번 도시 등을 순회하면서 결과를 `answer`에 추가한다.

## sol1. DFS + 백트래킹

```python

def solution(city, road):
    INF = float('inf')  # 무한대. 아직 속도 제한을 받지 않은 상태
    points = set(map(tuple, city))  # 모든 도시 좌표를 노드로 저장
    cameras = {}  # 카메라 좌표: 제한 속도

    # ========================================
    # 1. 그래프에 사용할 모든 노드(좌표) 찾기
    # ========================================

    # road의 각 원소:
    # (시작 x, 시작 y, 끝 x, 끝 y, 제한 속도)
    for x1, y1, x2, y2, limit in road:

        # 카메라는 도로의 정중앙에 있다고 가정
        # 예: (0, 0) ~ (10, 0) → 카메라 (5, 0)
        camera = ((x1 + x2) // 2, (y1 + y2) // 2)

        # 도로 양 끝점과 카메라 위치도 노드로 등록
        # set이므로 같은 좌표가 중복되어도 한 번만 저장
        points.update([(x1, y1), (x2, y2), camera])

        # 해당 좌표의 카메라 제한 속도 저장
        cameras[camera] = limit

    # ----------------------------------------
    # 서로 다른 도로가 만나는 교차점 찾기
    # ----------------------------------------

    # 첫 번째 도로를 하나씩 선택
    for i, (x1, y1, x2, y2, _) in enumerate(road):

        # 두 번째 도로 선택
        # road[i + 1:]을 사용하면 이미 비교한 도로쌍은 제외
        # 예: (0,1), (0,2), (1,2)만 비교
        for a1, b1, a2, b2, _ in road[i + 1:]:

            # 첫 번째 도로가 가로이고
            # 두 번째 도로가 세로인 경우
            if y1 == y2 and a1 == a2:

                # 가로 도로의 y와 세로 도로의 x가 만나는 좌표
                p = (a1, y1)

            # 첫 번째 도로가 세로이고
            # 두 번째 도로가 가로인 경우
            elif x1 == x2 and b1 == b2:

                p = (x1, b1)

            # 위 두 경우가 아니면 일단 건너뜀
            else:
                continue

            # 두 '직선'의 교차점이 실제 '도로 구간' 안에
            # 들어오는지 확인해야 함
            #
            # 예: 가로 도로 (0,0)~(5,0)
            #     세로 도로 (10,-5)~(10,5)
            #     직선끼리는 (10,0)에서 만나지만
            #     가로 도로가 x=5에서 끝나므로 교차점 아님

            x, y = p

            if (x1 <= x <= x2 and y1 <= y <= y2
                    and a1 <= x <= a2 and b1 <= y <= b2):

                # 실제 교차점이면 노드로 추가
                points.add(p)

    # ========================================
    # 2. 노드들을 연결해서 그래프 만들기
    # ========================================

    # graph = {현재 노드: [이동 가능한 다음 노드들]}
    graph = {}

    # 도로를 하나씩 확인
    for x1, y1, x2, y2, _ in road:

        # 전체 points 중 현재 도로 위에 있는 점만 선택
        #
        # 예: 전체 점이 A, B, C, D, E여도
        #     현재 도로 위에 A, B, C만 있으면
        #     nodes = [A, B, C]
        #
        # sorted()는 도로 위의 점들을 좌표순으로 정렬
        nodes = sorted(
            (x, y) for x, y in points
            if x1 <= x <= x2 and y1 <= y <= y2
        )

        # 인접한 두 점씩 연결
        #
        # nodes = [A, B, C]라면
        # (A, B), (B, C)만 연결
        #
        # A와 C를 바로 연결하지 않는 이유:
        # B에 카메라가 있을 수 있기 때문
        for a, b in zip(nodes, nodes[1:]):

            # A → B 연결
            graph.setdefault(a, []).append(b)

            # B → A 연결 (양방향 도로)
            graph.setdefault(b, []).append(a)

    # ========================================
    # 3. DFS로 각 노드까지의 최고 속도 구하기
    # ========================================

    # 첫 번째 도시에서 출발
    start = tuple(city[0])

    # best[노드] = 해당 노드까지 도달 가능한 최고 속도
    #
    # 처음에는 카메라를 지나지 않았으므로 무한대
    best = {start: INF}

    # DFS에 사용할 스택
    # (현재 위치, 현재까지 유지 가능한 최고 속도)
    stack = [(start, INF)]

    while stack:

        # 방문할 노드 하나 꺼내기
        now, speed = stack.pop()

        # 이미 더 좋은 속도로 이 노드에 도착한 적이 있다면
        # 지금 경로는 더 탐색할 필요 없음
        if speed < best[now]:
            continue

        # 현재 노드와 연결된 다음 노드들을 확인
        for nxt in graph.get(now, []):

            # 다음 노드에 카메라가 있다면
            # 현재 속도와 카메라 제한 속도 중 작은 값 선택
            #
            # 예: 현재 속도 80, 다음 카메라 제한 50
            #     → next_speed = 50
            #
            # 카메라가 없다면 INF를 사용하므로
            # 기존 speed가 그대로 유지됨
            next_speed = min(speed, cameras.get(nxt, INF))

            # 이전에 기록한 속도보다 더 좋은 경로를 발견했다면
            if next_speed > best.get(nxt, -1):

                # 최고 속도 갱신
                best[nxt] = next_speed

                # 이 경로에서 다음 노드로 계속 탐색
                stack.append((nxt, next_speed))

    # ========================================
    # 4. 각 도시의 최고 속도를 정답으로 반환
    # ========================================

    answer = []

    # 첫 번째 도시는 출발점이므로 제외
    for p in city[1:]:

        # 해당 도시까지 도달 가능한 최고 속도
        speed = best.get(tuple(p), INF)

        # INF라면 카메라 제한을 받지 않았다는 의미로
        # 이 코드에서는 0으로 반환
        answer.append(0 if speed == INF else speed)

    return answer
```

```
import heapq

def solution(city, road):
    INF = float('inf')
    m = len(road)

    # 1. 도로의 교차점, 도시, 카메라를 노드로 만든다.
    points = [set() for _ in range(m)]
    cameras = {}

    for i, (x1, y1, x2, y2, limit) in enumerate(road):
        points[i].add((x1, y1))
        points[i].add((x2, y2))

        camera = ((x1 + x2) // 2, (y1 + y2) // 2)
        points[i].add(camera)

        cameras[camera] = min(
            cameras.get(camera, INF), limit
        )

    # 좌표가 도로 위에 있는지 확인
    def on_road(x, y, r):
        x1, y1, x2, y2, _ = r
        return x1 <= x <= x2 and y1 <= y <= y2

    # 도시 위치 추가
    for i in range(m):
        for x, y in city:
            if on_road(x, y, road[i]):
                points[i].add((x, y))

    # 도로끼리 만나는 지점 찾기
    for i in range(m):
        x1, y1, x2, y2, _ = road[i]

        for j in range(i + 1, m):
            a1, b1, a2, b2, _ = road[j]
            cross = None

            if y1 == y2 and a1 == a2:
                cross = (a1, y1)

            elif x1 == x2 and b1 == b2:
                cross = (x1, b1)

            elif y1 == y2 and b1 == b2:
                left = max(x1, a1)
                right = min(x2, a2)
                if left == right:
                    cross = (left, y1)

            elif x1 == x2 and a1 == a2:
                bottom = max(y1, b1)
                top = min(y2, b2)
                if bottom == top:
                    cross = (x1, bottom)

            if cross is not None:
                x, y = cross
                if on_road(x, y, road[i]) and on_road(x, y, road[j]):
                    points[i].add(cross)
                    points[j].add(cross)

    # 2. 그래프 구성
    # 간선의 가중치는 양 끝 노드의 카메라 제한 속도 중 최솟값
    graph = {}

    for i, (x1, y1, x2, y2, limit) in enumerate(road):
        if y1 == y2:
            ordered = sorted(points[i], key=lambda p: p[0])
        else:
            ordered = sorted(points[i], key=lambda p: p[1])

        for j in range(len(ordered) - 1):
            a = ordered[j]
            b = ordered[j + 1]

            weight = min(
                cameras.get(a, INF),
                cameras.get(b, INF)
            )

            graph.setdefault(a, []).append((b, weight))
            graph.setdefault(b, []).append((a, weight))

    # 3. 최대 힙 다익스트라
    # 각 노드까지 가능한 최고 속도 저장
    start = tuple(city[0])
    best = {start: INF}

    # heapq는 최소 힙이므로 음수로 저장
    heap = [(-INF, start)]

    while heap:
        neg_speed, now = heapq.heappop(heap)
        speed = -neg_speed

        if speed < best[now]:
            continue

        for nxt, limit in graph.get(now, []):
            # 현재 경로에서 가능한 최고 속도
            next_speed = min(speed, limit)

            if next_speed > best.get(nxt, -1):
                best[nxt] = next_speed
                heapq.heappush(heap, (-next_speed, nxt))

    # 4. 각 도시의 정답 반환
    answer = []

    for x, y in city[1:]:
        speed = best[(x, y)]

        if speed == INF:
            answer.append(0)
        else:
            answer.append(speed)

    return answer
```
