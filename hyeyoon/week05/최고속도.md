
# 최고 속도

- 플랫폼: 프로그래머스
- 유형: 그래프, DFS, 백트래킹, 시뮬레이션
- 문제: https://school.programmers.co.kr/learn/courses/30/lessons/468376

## 접근방법

### 1. 도로를 그래프로 변환한다.

현재 도로는 그래프 형태가 아니라 두 지점의 좌표로 주어져 있다.

따라서 `road`를 순회하면서 각 도로를 구간으로 만들고, 도로끼리 교차하는 지점을 찾아야 한다.

- 가로 도로와 세로 도로가 교차하는지 확인한다.
- 도로가 겹치거나 만나는 지점을 찾는다.
- 도로의 양 끝점, 교차점, 도시, 카메라 위치를 노드로 만든다.
- 같은 도로에 존재하는 노드들을 순서대로 연결한다.

이렇게 하면 좌표로 표현된 도로를 그래프로 바꿀 수 있다.

### 2. DFS + 백트래킹으로 가능한 최고 속도를 구한다.

교차하는 지점을 그래프의 노드라고 생각하고 완전탐색으로 풀어보자.

출발 도시에서 다른 도시까지 이동하는 모든 경로를 탐색하면서, 각 경로의 최저 제한 속도를 저장한다.

**한 경로에서 가능한 최고 속도는 그 경로에서 만나는 제한 속도 중 최솟값이다.**

예를 들어 다음과 같은 경로가 있다고 하자.

- 경로 A: `100 → 60 → 90` → 최저 속도 `60`
- 경로 B: `80 → 80 → 70` → 최저 속도 `70`

따라서 가능한 최고 속도는 `max(60, 70) = 70`이다.

DFS로 탐색하면서 현재 경로의 최저 속도를 `min()`으로 갱신하고, 각 노드에 도착할 수 있는 최고 속도를 `max()` 개념으로 관리한다.

단, 모든 경로를 탐색하면 시간 초과가 발생할 수 있으므로 가지치기를 적용한다.

- 이전보다 높은 속도로 도착했다면 다시 탐색한다.
- 이전보다 낮거나 같은 속도로 도착했다면 탐색하지 않는다.

### 3. 모든 도시의 결과를 answer에 저장한다.

1번 도시에서 DFS를 한 번 실행하면 다른 도시들까지 도달 가능한 최고 속도를 구할 수 있다.

따라서 2번, 3번, 4번 도시 등을 순회하면서 결과를 `answer`에 추가한다.

## sol1. DFS + 백트래킹

```python
def solution(city, road):
    INF = float('inf')

    # 1. road를 통해서 for문을 돌리면서 노드를 찾음.
    # 현재 도로가 두 지점의 좌표로 주어지므로
    # 각 도로를 구간으로 만들고 겹치는 지점을 찾는다.

    points = [set() for _ in range(len(road))]
    cameras = {}

    for i, (x1, y1, x2, y2, limit) in enumerate(road):
        # 도로의 시작점과 끝점을 노드로 추가
        points[i].add((x1, y1))
        points[i].add((x2, y2))

        # 도로의 정중앙에 카메라가 존재
        cx = (x1 + x2) // 2
        cy = (y1 + y2) // 2
        camera = (cx, cy)

        points[i].add(camera)

        # 동일한 위치에 카메라가 여러 개라면
        # 더 낮은 제한 속도를 적용
        cameras[camera] = min(
            cameras.get(camera, INF), limit
        )

    # 특정 좌표가 도로 구간 위에 있는지 확인
    def on_road(x, y, r):
        x1, y1, x2, y2, limit = r

        return x1 <= x <= x2 and y1 <= y <= y2

    # 도시 위치도 그래프의 노드로 추가
    for i, r in enumerate(road):
        for x, y in city:
            if on_road(x, y, r):
                points[i].add((x, y))

    # 도로끼리 교차하는 지점을 찾는다.
    for i in range(len(road)):
        x1, y1, x2, y2, _ = road[i]

        for j in range(i + 1, len(road)):
            a1, b1, a2, b2, _ = road[j]

            cross = None

            if y1 == y2 and a1 == a2:
                # 가로 도로와 세로 도로
                cross = (a1, y1)

            elif x1 == x2 and b1 == b2:
                # 세로 도로와 가로 도로
                cross = (x1, b1)

            elif y1 == y2 and b1 == b2:
                # 두 도로가 모두 가로
                left = max(x1, a1)
                right = min(x2, a2)

                if left == right:
                    cross = (left, y1)

            elif x1 == x2 and a1 == a2:
                # 두 도로가 모두 세로
                bottom = max(y1, b1)
                top = min(y2, b2)

                if bottom == top:
                    cross = (x1, bottom)

            if cross is not None:
                x, y = cross

                if on_road(x, y, road[i]) and on_road(x, y, road[j]):
                    points[i].add(cross)
                    points[j].add(cross)

    # 2. 교차점을 그래프의 노드라고 생각하고,
    # DFS + 백트래킹으로 모든 경로를 탐색한다.

    graph = {}

    for i, r in enumerate(road):
        x1, y1, x2, y2, limit = r

        # 같은 도로 위의 노드들을 순서대로 정렬
        if y1 == y2:
            ordered = sorted(points[i], key=lambda p: p[0])
        else:
            ordered = sorted(points[i], key=lambda p: p[1])

        # 인접한 노드끼리 양방향 연결
        for j in range(len(ordered) - 1):
            a = ordered[j]
            b = ordered[j + 1]

            graph.setdefault(a, set()).add(b)
            graph.setdefault(b, set()).add(a)

    # 각 노드에 도착할 수 있는 최고 속도를 저장
    best = {}

    start = tuple(city[0])
    best[start] = INF

    # DFS를 위한 스택
    stack = [(start, INF)]

    while stack:
        now, speed = stack.pop()

        # 이전에 더 좋은 경로로 방문했다면 가지치기
        if speed < best[now]:
            continue

        for next_node in graph.get(now, []):
            # 다음 노드에 카메라가 있는지 확인
            limit = cameras.get(next_node, INF)

            # 해당 경로의 최저 제한 속도 갱신
            next_speed = min(speed, limit)

            # 더 좋은 경로를 발견했을 때만 갱신
            if next_speed > best.get(next_node, -1):
                best[next_node] = next_speed
                stack.append((next_node, next_speed))

    # 3. 모든 도시를 돌면서 answer 배열에 append한다.

    answer = []

    for x, y in city[1:]:
        speed = best.get((x, y), INF)

        # 카메라를 통과하지 않았다면 0
        if speed == INF:
            answer.append(0)
        else:
            answer.append(speed)

    return answer
```
