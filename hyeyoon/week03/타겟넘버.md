# 타겟 넘버 (DFS)

## 문제

n개의 음이 아닌 정수에 각각 `+` 또는 `-`를 적용해 타겟 넘버를 만드는 방법의 수를 구한다.

숫자의 순서는 바꿀 수 없다.

### 입출력 예시

| numbers | target | return |
|---|---|---|
| [1, 1, 1, 1, 1] | 3 | 5 |
| [4, 1, 2, 1] | 4 | 2 |

---

## 접근 방법

### 1. DFS 선택

첫 번째 숫자부터 마지막 숫자까지 `+`, `-` 두 가지 경우를 모두 탐색해야 하므로 DFS를 사용한다.

DFS에 전달할 인자는 다음과 같다.

- `i`: 현재 탐색할 숫자의 인덱스
- `now`: 현재까지 계산한 합계

```python
dfs(i, now)
```

### 2. 종료 조건

모든 숫자를 사용했을 때(`i == len(numbers)`) 탐색을 종료한다.

이때 합계가 `target`과 같으면 `1`, 다르면 `0`을 반환한다.

```python
if i == len(numbers):
    if now == target:
        return 1
    return 0
```

### 3. 재귀 호출

현재 숫자를 더하는 경우와 빼는 경우를 각각 탐색한다.

```python
return dfs(i + 1, now + numbers[i]) + dfs(i + 1, now - numbers[i])
```

각 재귀 호출에서 반환된 `1`을 합산하면 타겟 넘버를 만드는 전체 방법의 수가 된다.

---


---

## Sol . 최종 정답

```python
def solution(numbers, target):

    def dfs(i, now):
        if i == len(numbers):
            if now == target:
                return 1
            return 0

        return dfs(i + 1, now + numbers[i]) + dfs(i + 1, now - numbers[i])

    return dfs(0, 0)
```

---

## 시간복잡도

**O(2ⁿ)**

각 숫자마다 `+`, `-` 두 가지 선택지가 생기므로 탐색 경우의 수가 2ⁿ개다.

## 공간복잡도

**O(n)**

재귀 호출 횟수는 많지만, 콜스택에 동시에 쌓이는 최대 깊이는 n이다.

```text
              dfs(0)
             /      \
         dfs(1)     dfs(1)
         /   \       /   \
     dfs(2) dfs(2) dfs(2) dfs(2)
       ...
```

## 배운 점 및 느낀 점

**재귀 함수에서 `return 1`을 합산해 최종 정답을 구하는 방식**에 아직 익숙하지 않았다.

이번 문제를 통해 DFS가 마지막 단계에서 타겟에 도달하면 `1`, 그렇지 않으면 `0`을 반환하고, 각 재귀 호출의 반환값이 합산되어 최종 정답이 된다는 개념을 배웠다.

또한 DFS에서는 **종료 조건을 먼저 정의하고, 재귀 호출의 반환값을 어떻게 처리할지 결정하는 것**이 중요하다는 점을 알게 되었다.
